# 逗猫猎场 · 小程序项目档案

> 微信**小游戏**（compileType=game）｜横屏｜AppID 环境：测试/正式已配置（不记敏感值明文）

## 一、项目概况
- 项目名：逗猫猎场（逗猫触屏玩具·微信小游戏版）
- 类型：微信小游戏（非标准小程序，无 WXML/WXSS 页面，全 Canvas 绘制）
- 横屏 landscape，showStatusBar=false
- 主入口：`game.js`（62.7 KB）；逻辑模块在 `js/`；开放数据域 `openDataContext/`（8.1 KB，排行榜）
- assets/ 已配置为**子包**（game.json `subpackages: [{name:"assets", root:"assets/"}]`）

## 二、技术栈
- 原生小游戏框架，无第三方框架
- Canvas 2D 绘制（js/draw.js、js/scenery.js）
- 音频：WebAudioContext 合成兜底 + InnerAudioContext 真实录音（mp3/wav）
- 资源加载：`wx.loadSubpackage({name:"assets"})` 门控 + `G.assetsReady` 加载屏
- 基础库版本需核实（libVersion=3.18.0，以官方文档为准）

## 四、启动流程
1. 主包代码 ≈1MB 加载并执行
2. 立即 `wx.loadSubpackage({name:"assets"})` 拉 **3.74MB** 子包（带进度条加载屏，瘦身后原 14MB→3.74MB，真机首启等待大幅缩短）
3. 子包到位 → `G.assetsReady=true` → 首页 `initHomeImages` 异步加载 7 张图（不阻塞）
4. 进入玩法才 `preload*` 音频（mp3/wav 此时才下载）

### 加载屏（game.js `drawAssetsLoadingScreen`，2026-11-25 重做）
- 暖砂 4 段渐变 + "加载中…" + 进度条（**小灰鼠跑在进度上、终点一块奶酪**）+ 流光 + 百分比 + 每 2.6s 轮换 8 条主题提示。
- **布局约定**：在「虚拟手机尺寸」`W/S × H/S`（与 ui.js `layout()` 同一套）里布局，外层 `ctx.scale(S)` 放大铺满整窗。⚠️ 若直接用 `G.platform.W/H` 不除 `S`，平板/高分屏（S>1）内容会溢出屏幕——这是本屏踩过的坑。
- 进度缓动跟随真实值（`onProgressUpdate` 跳变直接画会一顿一顿）。出错显示"资源加载失败/请退出后重新进入"+ 错误详情。
