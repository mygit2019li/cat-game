逗猫猎场 · 倒计时界面重设计

两种风格，同一套倒计时场景

本次覆盖项目里与“倒计时 / 等待 / 剩余时间”相关的界面：开局前 3 秒倒计时、对局 HUD 剩余时间药丸、暂停页、结算页，以及电子猫粮下次出粮倒计时。两种风格使用相同内容，只改变视觉方向，便于直接比较。

手机预览为静态高保真稿；真实动效、触摸热区与 Canvas 实现在选定风格后落地。

风格 A · 夜航猎手

Dark Tactical Countdown

把倒计时做成一局开始前的“瞄准镜”。深青夜色、同心刻度环、高对比数字让剩余秒数成为唯一主角；HUD 保持轻量半透明，暗场玩法（激光、暗夜荧光）里不抢猎物。

  • 视觉核心：238px 环形进度 + 94px 数字，开局仪式感强。
  • 适合：激光暗室、暗夜荧光、捕鼠、青蛙等偏暗场景；也适合夜间长时间给猫自玩。
  • 风险：浅色背景玩法（蝴蝶、蝌蚪白纸）需要从深转浅做一次过渡，避免开场太“黑”。

风格 B · 阳光庭院

Light Garden Countdown

延续现有浅色青绿基线，把倒计时做成“庭院里的出发牌”。白色圆角卡片、青绿到琥珀的进度条、柔和阴影，整体更轻松、更偏宠物日常。

  • 视觉核心：白色卡片 + 86px 大数字 + 青绿进度条，识别直接、制作成本低。
  • 适合：蝴蝶花园、蝌蚪白纸、鱼池等浅色场景；和首页现有 UI 最连续。
  • 风险：暗场玩法需要给 HUD 和倒计时加一层“亮色浮层”，否则白字白底或黑字黑底会不稳。
比较维度 风格 A · 夜航猎手 风格 B · 阳光庭院
第一印象更游戏化、更有“开拍”感，倒计时本身成为主视觉。更生活化、更轻盈，和首页 / 设置 / 记录的现有浅色体系一致。
倒计时表达环形进度 + 刻度 + 大数字，强调“马上开始”。卡片 + 横向进度条 + 大数字，强调“准备出发”。
HUD 可读性暗场强：激光、暗夜荧光、捕鼠等场景不压猎物。亮场强：浅色场景更清爽；暗场需要额外加深药丸。
与现有 UI 连续性首页仍是浅色，倒计时变深色会带来一次明显转场；需要处理好过渡。延续现有浅色青绿体系，改动范围更集中。
电子猫粮出粮倒计时可用“LCD 真空荧光屏”做拟物小屏，和机器造型强关联。用浅色状态卡 + 青绿进度，更贴合设置页，不像设备屏幕那么重。
实现成本（Canvas）中等偏高：需要环形渐变、刻度、暗色遮罩，暗场与亮场两套 HUD 令牌。中等：主要是白卡片、进度条与药丸颜色令牌，现有绘制函数更容易扩展。
推荐场景若希望小游戏更有“玩法仪式感”，优先 A。若希望整体产品更稳、更宠物日常，优先 B。

说明：本稿为设计比较稿，未改动 game.js、js/ui.js、js/feeder.js。手机内的画面为可预览的 HTML 高保真模拟；真实 Canvas 实现会复用现有 ui.drawCountdown、ui.drawHud、ui.drawPause、ui.drawResult 与电子猫粮 LCD 绘制逻辑，替换颜色令牌、形状和动效参数。
