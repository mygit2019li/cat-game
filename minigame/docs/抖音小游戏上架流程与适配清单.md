# 逗猫猎场 · 抖音小游戏上架流程与适配清单

> 调研日期：2026-11-27｜依据：抖音开放平台官方文档 developer.open-douyin.com
> 源项目：微信小游戏（compileType=game）`wx4ca485feef1515ee`，横屏，纯 Canvas 绘制

---

## 一、先看结论

| 问题 | 答案 |
|---|---|
| 能不能搬？ | **能**，但不是「打包上传」那么简单。微信与抖音 API 同名不同前缀（`wx.*` → `tt.*`），约 90% 机械替换可自动化 |
| 你项目最大的坑 | **广告模型要重写**——微信的 `wx.createCustomAd`（原生模板浮卡）在抖音**不存在**，抖音只有 banner / 激励视频 / 插屏 / GridGamePanel 四种 |
| 第二个坑 | **录屏分享是抖音的命门**——抖音流量靠短视频分发，你项目现在只有录音、没有录屏，等于放弃了抖音最主要的分发通道 |
| 第三个坑 | **侧边栏复访是「必接」能力**，不接 `tt.navigateToScene` 版本直接上传失败，会被预检拦截 |
| 资质硬门槛 | 软著（必填）+ 小游戏备案（无版号时）+ ICP 备案（所有类型） |
| 包体 | 你现在主包 1MB / assets 子包 2.81MB，抖音上限 20MB，**完全够用，不用瘦身** |

**总工期预估**：代码适配 3–5 天（广告重写占 2 天、录屏分享新增占 1 天）；资质流程并行跑，软著 30–60 个工作日（免费）或 10–15 天（加急）是关键路径。

## 二、上架全流程（官方口径）

```
入驻主体认证  →  创建小游戏  →  完善基础信息  →  上传版本
                                                      ↓
发布上线  ←  ICP 备案  ←  小游戏备案  ←  版本提审（预检 + 审核）
```

### 第 0 步 · 入驻与主体认证

**入口**：抖音开放平台 `developer.open-douyin.com` → 注册（手机号 / 邮箱 / 抖音号三选一）

主体认证分两类，**选错后面不能改**（主体资质审核通过后不支持修改主体类型和统一社会信用代码）：

| 主体 | 需提交材料 | 审核时效 | 可建小游戏数 | 变现能力 |
|---|---|---|---|---|
| **个人** | 身份证正反面照片（≤5M，需边角完整）+ 姓名 + 证件号 + 有效期 + 地区；**手机号实名认证 或 银行账户实名认证**（二选一） | 约 1 个工作日 | 50 个 | 纯广告（穿山甲），**无法开通内购**（内购需版号，个人拿不到） |
| **企业** | 营业执照原件照片（≤5M，无水印 / 复印件需手写"与原件一致"并盖公章）+ 统一社会信用代码 + 法人信息 + 注册地址 + 注册资本 + 运营人信息 | 约 3 个工作日 | 100 个 | 广告 + 内购（需版号） |

**对公验证**（仅企业/个体户，四选一）：
- 法定代表人人脸识别（支付宝）— 实时
- 银行账户实名认证 — 实时
- 平台向客户打款 — 0–2 小时（单次仅 2 次机会）
- 客户向平台打款 — 1–2 个工作日

对公验证有效期 1 年，过期会导致无法创建小游戏和生成结算单。

**个人主体够用吗？** 够，但只有广告变现。若想开内购，必须走企业主体 + 版号，个人主体基本无路径。
另外激励视频广告位对个人开发者有门槛：**前一日 DAU > 50** 才能创建。

### 第 1 步 · 创建小游戏

控制台 → 小游戏 → 创建小游戏，填：

- **小游戏开发引擎**：普通小游戏 / Unity 小游戏 —— **创建后不可跨类别更改，选错只能重来**
- **小游戏名称**：4–20 字符（汉字算 2 字符），正式上架前可保留 30 天，超时释放
- 联系人姓名 / 电话 / 邮箱

名称审核细则（会打回的点）：
- 不可用单个名词（"摩托""恐龙"），不可用通用游戏名（"斗地主""麻将"）
- 不可混商业化用语、热门应用名、侵犯他人知识产权
- 名称信息表达必须与游戏内容一致
- **建议与软著名称保持一致**，否则可能无法备案、无法广告投放
- 正式上架后每个自然年可改 2 次

### 第 2 步 · 完善基础信息（统一审核，1–3 工作日）

入口：开发者后台 → 总览页 → 完善基础信息 → 基础信息 → 查看详情

| 字段 | 要求 |
|---|---|
| 小游戏名称 | 同上 |
| 小游戏简介 | ≤ **60 字**，一句话讲玩法 |
| 小游戏图标 | **600×600**，png/jpeg/jpg/bmp，≤ **6M**，**不带圆角、水印、二维码** |
| 小游戏详细介绍 | **120–300 字**（不能少于 120 字），写清背景、角色、场景、玩法、系统、特点、使用方法 |
| 小游戏类别 / 题材 / 画风 | 按指引选择，填错平台会强制修正且**不可二次修改** |
| 基础库最低版本号 | 建议设高，屏蔽老环境 |
| 小游戏最低版本号 | 仅线上版本生效 |

### 第 3 步 · 资质信息（卡脖子的一步）

**3.1 计算机软件著作权登记证书（软著）—— 所有游戏均需提供**

- 平台支持**电子软著**用于准入，但**不支持用于小游戏备案**——备案必须用国家版权局发放的《软件著作权登记证书》
- **著作权人须与平台主体名称完全一致**，不一致须上传盖章授权书
- **同一软著仅支持一款小游戏在线运营**，已在运营的软著不得二次使用
- **小游戏名称须与软著登记名称（或简称）一致**；可用全称（忽略"app/游戏软件"等后缀），可用简称（须完全一致），软著内的特殊符号（冒号、横线）可在名称中省略
- 官方推荐走**火山引擎软著特惠页面**申请

> 你项目名"逗猫猎场"：软著登记名请就用这个名字，别加"小游戏""app"之类后缀导致一致性审核不过。

**3.2 游戏自审自查报告**
自 7 月 11 日起改为**后台直接勾选确认**，无需另行上传报告。但需在「基础信息 → 资质信息 → 游戏自审自查报告」处确认，内容要真实合规。

**3.3 广电总局版号批文**
仅两种情况需要：① 开通内购的企业小游戏 ② 已有版号的游戏。
- 版号游戏名称须与平台名称**完全一致**（含"游戏"等后缀词）
- 运营单位名称须与平台主体名称完全一致，否则提供授权证明
- 官网查询内容与上传内容须完全一致（游戏名称、出版单位、内容类别、批文号、游戏版号）
- 版号类型须为移动端/移动
- 《网络游戏出版物号》(ISBN) 格式规范填写，中宣部备案识别码需绑定「北京抖音信息服务有限公司」

**3.4 商标或 IP 资质**
用了第三方游戏/文学影视/音乐素材才需要。最多 10 对材料，原件+授权书独立审核，材料多可拼接上传。

**3.5 小游戏隐私政策**
平台自带隐私政策模板，**协议内小游戏名称、主体名称与开发者后台信息一致，不支持自定义编辑**。发布后向玩家展示。

### 第 4 步 · 代码适配与上传

**官方搬家工具**（省事但要盯着日志）：
- IDE 内置：右上角「搬家」按钮 → 选微信项目目录 + 输出目录
- NPM 包：`npm i -g wx-to-tt` → `wx2tt --input=./wxProjects/demo --output=./ttProjects/demo`
- 转换日志在输出目录 `__wxToTT/report/index.html`，**必须逐条看**，标出来的不支持项要手工改

**包体限制**（你项目完全达标）：

| 项 | 抖音上限 | 你的现状 |
|---|---|---|
| 不分包总包 | 20 MB | — |
| 分包后整体 | 20 MB | ~3.8 MB ✅ |
| 单个主包 | **4 MB** | ~1 MB ✅ |
| 单个子包 | 20 MB | 2.81 MB ✅ |
| 开放数据域 | 4 MB | 8 KB ✅ |

上传：开发者工具 → 填版本号（`主.子[.修正]`）+ 更新日志 → 上传。支持 25 个并行测试通道（默认通道 + 通道 1–24）。

### 第 5 步 · 版本提审（预检 + 审核）

**上传即预检**，这一步会直接拦你：
- **必接能力：侧边栏复访** —— 必须调用 `tt.navigateToScene`，未接入**版本上传直接失败**
- 重点推荐能力（不拦截，只提示）：录屏、分享等

**审核要点（会打回的）**：
- 截图与游戏内文字**尽量全中文**，大面积英文直接打回
- 简介里**不能提微信或其他平台**
- 游戏内名称、截图上的名称、后台填的名称，**三处必须一模一样**
- 首次上线需 QA 回归，1–2 个工作日；**自 2026 年 4 月 20 日起提审自动上线至所有已接入的合作 App，QA 默认回归多端**，任一宿主不过则整版退回
- 用了网络请求必须在后台配 https/wss 安全域名白名单
- 基础审核 1–3 个工作日（周六周日有值班），无催审流程

### 第 6 步 · 小游戏备案（无版号才需要）

**平台代申报，无需开发者手动操作**，触发条件是两步都通过：
1. 基础信息审核通过
2. 版本提审审核通过

之后平台自动申报，你只需去「设置 → 基础设置 → 资质信息 → 小游戏备案申请」看进度。
**平台不保证备案时效**（依监管实际处理）。已有版号的游戏跳过这步。

### 第 7 步 · ICP 备案（所有类型小游戏都要做）

顺序：**小游戏备案通过 → ICP 备案入口才开放**（有版号的直接开放）。

填写内容：主办单位信息、主办单位负责人信息、备案小游戏信息、小游戏负责人信息 + 附件。

- 平台审核 1–3 个工作日 → 管局审核（1–3 周）→ **工信部短信核验**（务必接）
- **提交后无法撤回**，填错只能等驳回重来
- 部分信息自动从小游戏信息带入，填错要先改基础信息
- 类目默认「休闲娱乐-游戏」，小游戏类型建议选「生活服务-工具」
- 主办单位负责人要求因省份而异（部分省份必须是法人，部分可授权，部分不需授权书）

### 第 8 步 · 发布

版本审核通过 + ICP 备案完成 → 后台点「发布」。
上线 15 天内可申请**新游冷启流量**（平台免费赠送，冷启公式看 icon 点击率与人均游戏时长）。
上线后配置：流量主（广告）、素材管理（录屏素材库，喂推荐流）。

### 3.2 必须重写 / 需决策的

| 微信 API | 用量 | 抖音替代 | 风险 |
|---|---|---|---|
| **`wx.createCustomAd`** | 5 处，7 个页面浮卡广告 | **抖音无此 API**。只能改用 `tt.createBannerAd`（横屏宽 128–208 设备像素）/ `tt.createRewardedVideoAd` / `tt.createInterstitialAd` / `tt.createGridGamePanel` | 🔴 **最高**。你 `js/ad.js` 整套「浮卡自定位」逻辑（fit/safeArea/避胶囊/最小宽 120px）全部作废，要重新设计广告位模型 |
| **`wx.getMenuButtonBoundingClientRect`** | 2 处 | `tt.getMenuButtonLayout` | 🟠 **单位不同**：微信返回 px，抖音返回 **dp**，坐标换算要改。抖音胶囊旁还有「游戏中心」按钮，官方无接口获取，需自行加偏移 |
| **`wx.chooseMessageFile`** | 4 处（从微信聊天选文件/图片） | 抖音**无对应 API** | 🟠 用户素材选择流程要降级到 `tt.chooseImage` / `tt.chooseVideo` |
| **`wx.reportEvent`** | 3 处 | 抖音无；用 `tt.reportAnalytics` / `tt.reportScene` | 🟡 埋点方案要重映射 |
| **`wx.createWebAudioContext`** | 2 处 | 抖音用 `tt.getAudioContext`（返回 AudioContext，功能等价） | 🟡 改个方法名 |
| **`wx.env.USER_DATA_PATH`** | 6 处 | 抖音路径体系不同，需实测确认 | 🟡 影响 `saveAsset`/`removeAsset` 落盘 |
| **`wx.onWindowResize`** | 1 处 | 抖音横竖屏切换行为不同，需实测 | 🟡 你项目是横屏锁定，风险中等 |
| **`scope.WxFriendInteraction`** | 授权逻辑 | 抖音无此 scope | 🟡 好友排行榜授权链要重设计 |
| — | — | **新增 `tt.getGameRecorderManager`** | 🔴 **新增功能**。抖音最核心的分发能力，见下节 |

### 3.3 必须新增的两块抖音原生能力

**① 侧边栏复访（必接，不做就上传失败）**

```js
// game.js 最顶部（越早越好，晚了收不到回调）
tt.onShow((res) => {
  if (res.launch_from === 'homepage' && res.location === 'sidebar_card') {
    // 用户从抖音首页侧边栏进入 → 发复访奖励
    giveSidebarReward();
  }
});
```
点击引导图标时调 `tt.navigateToScene({ scene: 'sidebar' })`。
场景值：抖音 `021036`、抖极 `101036`、番茄小说 `181036`、红果短剧 `261036`。
官方数据：接入后平均次留 +12%、7 日留 +8%。

**② 录屏分享（抖音流量命门）**

```js
const recorder = tt.getGameRecorderManager();
recorder.start({ duration: 30 });
recorder.onStop((res) => {
  recorder.clipVideo({ path: res.videoPath, success(r) { /* r.videoPath → 发布 */ } });
});
recorder.recordClip({ timeRange: [3, 3] });  // 记录精彩瞬间
```
- 只能录到你的 Canvas 内容，**广告、showToast 等原生层录不到**
- 支持录游戏音频
- **开发者工具不支持录屏调试，必须真机测**
- 配套能力：录屏带配乐、剪映视频模板、素材管理（录屏素材库喂推荐流）
- 官方录制建议：Android + 抖音 ≥36.6.0 + 分辨率 ≥1560×720 + 开声音；基础玩法录 15–30 秒，高光玩法 15–45 秒

> 这块你项目完全没有。抖音是「内容驱动」平台——没有录屏就没有短视频素材，冷启流量给再多也接不住。

### 3.4 录屏/分享注意事项

- 微信的 `wx.shareAppMessage` 分享的是卡片；抖音的 `tt.shareAppMessage` 配合 `templateId`（后台审核通过的分享素材模板）
- 分享素材图必须是**原创内容**，否则审核失败
- 加载图**不能显示进度条/数值**，不能展示货币、等级、关卡、ID 等数值
- PC 抖音端不支持录屏、分享、群聊、侧边栏跳转、震动、陀螺仪

## 五、时间线与风险

| 环节 | 时长 | 备注 |
|---|---|---|
| 主体认证 | 1（个人）/ 3（企业）工作日 | 不可变更主体类型 |
| 软著（免费） | 30–60 个工作日 | 🔴 **关键路径**，最先启动 |
| 软著（加急代办） | 10–15 天 | 数百至上千元 |
| 基础信息审核 | 1–3 工作日 | |
| 版本提审 | 1–3 工作日 + QA 回归 1–2 工作日 | 多端回归 |
| 小游戏备案 | 平台不保证 | 依监管实际处理 |
| ICP 备案 | 平台 1–3 工作日 + 管局 1–3 周 + 短信核验 | 提交后不可撤回 |
| **代码适配** | **3–5 天** | 广告重写 2 天 + 录屏新增 1 天 + 其余 1–2 天 |

**最容易翻车的 5 个点**：
1. 软著名称与小游戏名称不一致 → 备案和广告投放都过不去
2. 小游戏备案 ≠ ICP 备案，顺序不能颠倒
3. ICP 备案提交后无法撤回，填之前逐字核对
4. 截图里有英文 / 简介提了微信 → 直接打回
5. 忘接 `tt.navigateToScene` → 版本上传直接失败
