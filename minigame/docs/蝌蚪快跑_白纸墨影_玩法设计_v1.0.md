# 蝌蚪快跑 · 白纸墨影 — 玩法与页面设计 v1.0

> 范围：`frog` 玩法组内的第二张卡「蝌蚪快跑」。
> 一句话：**纯白画面里只有一只黑色蝌蚪，从随机一边高速横穿；它碰到边缘会折返，折返的 0.22 秒是唯一慢下来的时刻，也是唯一值 2 分的时刻。**

---

## 1. 核心循环与设计意图

```
随机边出现 → 直线横穿（轻微摆尾） → 触边折返 / 穿出画面
     ↑                                      │
     └──── 0.5–0.8s 冷却 ← 被拍中（墨爆） ───┘
                                    └→ 漏击：连击 -3
```

设计意图只有三条：

1. **路线必须可读。** 不做随机闲游/随机疾冲，猫看到的每一段直线就是它真实要走的路。
2. **难度只加在"速度与频率"上，不加在"不可预测"上。** 折返是唯一的变量，且有淡灰预告环。
3. **白纸上只能有黑。** 所有反馈都用黑/灰表达，避免彩色特效把猎物淹没。

## 2. 视觉层级与黑白对比

| 层级 | 元素 | 处理 |
|---|---|---|
| L0 底 | 纸面 | `#FFFFFF` 纯白，仅外沿 4% 收 ≤3% 灰；中心 96% 保持纯白 |
| L1 主 | 蝌蚪剪影 | `#0B0C0E` 头 + 收细尾带；白色眼睛（负空间） |
| L2 次 | 轨迹感 | 身后 2 层 5.5%/3.7% 残影；游动水痕 13% 灰 |
| L3 提示 | 折返环 / 命中环 | 28% / 58% 灰，只在事件发生的 0.3–0.6s 内出现 |
| L4 HUD | 倒计时 / 捕获 / 连击 / 漏击 | 深色药丸 + 白字，压在画面顶部，不进入可玩区 |

- **对比度**：`#0B0C0E` 对 `#FFFFFF` ≈ **19.7:1**（WCAG AAA 阈值 7:1）。这是屏幕能给的最大黑白差，远距离、猫的对比敏感度下降时仍然成立。
- **尺寸层级**：小圆头 30×22 设计像素（随难度体型倍率 0.85–1.3），尾长 77–94（7 节 × 11px），头身比约 1:3；HUD 字号 12–15。猎物始终是画面里最大的深色块。
- **面部**：头越小，眼睛越重要。两只白圈（直径 6.8）+ 深色瞳孔（3.1）+ 一点高光，是全身唯一的高对比细节，保证远距离能读成"有脸的生物"而不是一团黑。
- **位置层级**：可玩区 `bounds` 内不放任何常驻装饰；HUD 与暂停键都在安全区，且蝌蚪贴边折返时不会进入 HUD 带。
- **动势层级**：画面里同时只有 1–3 个移动物，全部同向不同角；没有背景粒子抢注意力。

### 2.1 造型可选（四种，均只使用黑/灰）

| 造型 | 画法 | 适用 |
|---|---|---|
| 墨影 `ink` | 实心剪影 + 白眼睛（默认） | 远距离、弱光、猫的对比敏感度下降时最稳 |
| 线条 `line` | 空心勾边（2.6px）+ 黑点眼 + 短嘴弧 | 简笔画风格，画面最轻 |
| 水墨 `brush` | 不规则墨团 + 主副两笔尾带 + 尾部飞白 | 手绘感，边缘有浓淡 |
| 一笔 `dash` | 头尾连成一个逗号，无脖颈 | 极简，移动时最像"一个笔触" |

四种造型共用同一套头/尾坐标（`tailPoints`），**切换只改画法，不改命中判定**；选择存在 `config.tadStyle`，跨局记忆。

## 3. 运动轨迹

### 3.1 形态

| 形态 | 触发 | 说明 |
|---|---|---|
| 入场直线 | 出生 | 从边界外 30px 处以 1.16× 速度冲入，航向与边法线夹角 ≤ ±19° |
| 巡航直线 + 摆尾 | 常态 | 主航向不变；垂直方向叠加正弦位移，形成轻微 S 形，不改变可读的主方向 |
| 折返曲线 | 触边且未超折返上限 | 主航向按边做镜面反射 + ±19° 随机；0.22s 内用 smoothstep 插值转向，身体走一段 C 形弧 |
| 离场 | 折返次数用尽 / 存活超时 / 折返概率未命中 | 保持原方向穿出画面 |

折返反射保证"切向速度连续"，所以看起来是**贴着边拐了一下**，而不是弹球式的硬反弹。

### 3.2 速度曲线

```
v(t) = v_base × √S × 难度 × 自适应 × 连击 × foldK × entryK × startleK
```

| 系数 | 取值 | 作用 |
|---|---|---|
| `v_base` | 228–286 / 272–336 / 318–392（阶段 1/2/3） | 阶段主难度 |
| `√S` | 大屏按面积开方放大 | 保持相对速度手感 |
| `entryK` | 1.16 → 1.00 线性回落（0.26s） | 冲进来，然后进入巡航 |
| `foldK` | 0.62 → 1.00（0.22s） | 折返是唯一速度低谷，命中窗口 |
| `startleK` | 1.24（0.55s） | 拍空且落点距蝌蚪 <120px 时的短促受惊 |
| 连击 | 1.00 / 1.12 / 1.25 / 1.45（5/10/15 连） | 只走全局 `COMBO_TIERS`，**不二次叠加** |

> 早期版本在局部再乘一次连击系数，15 连时实测 1.7×，超出可读上限；已移除。

### 3.3 折返规则

- 每次触边**独立判定**：`random < foldP` 且未超过 `foldMax` 且未超存活上限 → 折返，否则离场。
- 折返后强制新航向的"朝内分量 ≥ 0.2"，并给 0.2s 的免折返冷却，避免贴边时连续触发把身体卡在边界。
- 单只上限：阶段 1/2/3 分别 2/2/3 次。**上限用尽后下一次触边必定离场**，形成明确的漏击压力。

## 4. 命中判定与碰撞体积

| 部位 | 判定形状 | 尺寸（标准难度、S=1） | 依据 |
|---|---|---|---|
| 头 | 轴对齐矩形（跟随头部中心） | 40 × 30 × **1.50** ≈ **60 × 45** | 手指接触面积约 44×44，猎物高速移动，需 ≥1.3 倍视觉体 |
| 尾 | 7 个圆，沿可见尾带 | 半径 `(5.0−i×0.58) × 1.3 + 8px` | 尾带是可见身体的一部分，不判会"看着拍到却没算" |
| 折返窗 | 头部矩形 ×1.15 | ≈ 71 × 53 | 唯一速度低谷，放宽 15% 作为奖励窗 |

- 判定用**可见坐标**：`tailPoints()` 同时供绘制与判定，摆尾幅度不会造成"图判分离"。
- 保护期：入场 0.24s、受击后 0.24s 不可命中，避免一次扑击重复计分。
- 失败宽容：拍偏不扣分，只把 120px 内的蝌蚪惊一下（加速 0.55s + 最多偏转 0.5rad），**保留玩家已读到的路线**。

## 5. 得分、连击与漏击

| 事件 | 分数 | 连击 | 反馈 |
|---|---|---|---|
| 普通命中 | +1 | +1 | 墨点爆散 + 灰环 + 短音 |
| **折返截击**（折返弧内命中） | **+2** | +1 | 更大的墨爆 + 双环 + 高音确认 + "折返截击 +2" |
| 漏击（完整穿出画面） | 0 | **−3**（下限 0） | 边缘灰环 + 低频"噗" + HUD 漏击 +1 |
| 拍空（未命中） | 0 | 附近 ≤140px 时减半；拍空气不清 | 灰色涟漪 |

- 漏击**每只每次只记一次**（`tadMissed` 锁），不会因为重生动画重复扣。
- HUD：捕获数、连击（≥2 显示）、漏击（>0 显示，≥3 加重色）。
- 结算：`bonusTag` 汇总"含折返截击 ×N · 漏击 M 次"。

## 6. 难度与刷新节奏

| 阶段 | 时间（60s 局） | 巡航速度 | 折返概率 | 折返上限 | 同屏基线 | 命中后重生 |
|---|---|---|---|---|---|---|
| 1 | 0–18s | 228–286 | 72% | 2 | 1 只 | 0.95–1.30s |
| 2 | 18–48s | 272–336 | 62% | 2 | 2 只 | 0.80–1.05s |
| 3 | 48–60s | 318–392 | 52% | 3 | 3 只 | 0.66–0.90s |

- 折返概率**随阶段下降**：后期更倾向直接穿出画面，漏击压力上升，但折返窗口仍存在（52%）。
- 同屏数量以阶段为基线（1→2→3），命中表现好可在 8s 评估窗口内 +1（上限 3）；连续两周期命中 ≤2 则回落到基线。
- 漏击后 0.36–0.56s 就回场，比命中后的冷却更短——避免"漏一只就一直少一只"。
- 自适应辅助（既有系统）在连续漏击时放大体型、放慢速度，并在辅助期间冻结加数量。

## 7. 状态与反馈设计

| 状态 | 时长 | 表现 | 声音 |
|---|---|---|---|
| 出生 | 0.26s | 从画外 30px 游入，淡入 + 体型 0.72→1.0 | 无（避免和命中音打架） |
| 巡航 | — | 摆尾 + 2 层残影 + 极淡水痕 | 无 |
| 折返 | 0.22s | 速度 62%，头侧 28%/13% 双灰环，身体走 C 弧 | 极轻的折返环音（可选） |
| 命中 | 0.26s | 中心墨团 + 15–22 粒墨点 + 2 道方向墨线 + 1–2 圈灰环；剪影同步淡出 | 纸面「哒」+ 低频；折返命中加高音 |
| 冷却 | 0.66–1.3s | 完全不可见、不可拍 | 无 |
| 重生 | 0.26s | 从随机边（避免同一边）游入 | 无 |
| 漏击 | 0.18s 淡出 | 边缘灰环 + 夹回画面内的"漏击"提示 | 低频「噗」 |

状态机只有 6 个，且每个状态都有唯一的视觉出口，不叠两层特效。

## 8. 边界与重生规则

- **可玩区**：`G.bounds()`，四边留 20px + 安全区；外沿画一圈 7.5% 灰的 1px 内框，作为折返线。
- **触边判定**：以头部中心越界 2px 为准，让身体能完整游出画面，不会"半只卡在边上"。
- **折返落点**：夹回边界内 7px，并强制朝内，避免连续触边。
- **重生边**：左/右各 40%，上/下各 10%（横穿读感最好）；**70% 概率避开上一次的出生边**。
- **重生位置**：距边 30px 的画外，沿边随机分布（12%–88%），不与上一位置重叠。
- **漏击判定**：只有"完整穿出"才算；被拍中不算。

## 9. 页面结构

### 开始
首页「青蛙池塘」→ 圆形开始 → 玩法卡（青蛙 / 蝌蚪）→ 选中蝌蚪 → **直接开局**（只有一套布景，不再弹场景卡）。
卡片页第三列是「蝌蚪造型」：四个色块即时切换，卡片大图同步预览；该项替代了蝌蚪模式无意义的环境音开关。
倒计时蒙层保留 3-2-1，并加一行规则：`点中黑蝌蚪 · 折返时 +2`。

### 暂停
长按右上角暂停键 600ms；白色面板保留「继续本局 / 结束本局」，蝌蚪模式追加一行
`折返瞬间命中 +2 · 漏击 1 次扣 3 连击`。

### 结算
沿用统一结算页；模式名「蝌蚪快跑」，副标题汇总 `含折返截击 ×N · 漏击 M 次`。
四格数据仍是「触碰 / 捕获 / 命中率 / 最高连击」。

## 10. 移动端适配与操作手感

- **触点坐标**：UI 按钮在虚拟空间（×S），猎物在真实画布空间（不乘 S）——两套坐标不能混用。
- **命中区**：最小边 46 设计像素，满足手指 44px 基准；折返窗再放宽 15%。
- **反馈延迟**：命中在 `touchstart` 同帧触发，不等 `touchend`；视觉反馈 0–1 帧内出现。
- **震动**：屏幕抖动从 8 降到 5，白纸画面里过强会像"页面在闪"。
- **横竖屏**：数量、HUD、暂停键都走既有安全区与 `ks` 缩放；1080×608 / 852×393 / 390×844 三档实测无重叠。
- **防误触**：沿用首次进局的系统防误触引导。

## 11. 节奏平衡与性能

**节奏目标（60s 局）**
- 单只蝌蚪寿命 3–7s，横穿 1.5–2s；每分钟约 10–12 次触边事件、5–10 次折返。
- 主动玩家：命中 12–20 次，连击 5–10；被动玩家：每分钟约 10 次漏击，连击长期为 0。
- 折返命中占比目标 20–35%（+2 不能成为主要得分来源，否则普通命中失去意义）。

**性能预算**

| 项 | 上限 | 实测 |
|---|---|---|
| 单只更新开销 | <0.05ms/帧 | 0.0008ms（Node 仿真） |
| 同时猎物 | 3 | 3 |
| 墨点粒子 | 90（池上限） | 命中瞬间 15–22 |
| 全屏渐变 | 1 个/帧（已缓存） | 缓存后 0 次新建 |
| 帧率 | 60fps | 1080×608@dpr2、3 只同屏：60.3fps |

- 白纸底渐变按尺寸缓存；描边只画 1px 内框。
- 尾带用一次多边形填充，不用逐节 `arc`；残影只画 2 层。
- 粒子全部走既有 `PUSH` 上限池，超限自动淘汰最旧，不会在长时间游玩后累积。

## 12. 可调参数

`js/config.js`

```js
G.TAD = {                     // 阶段表
  1: { spd: [228, 286], foldP: 0.72, foldMax: 2, alive: 7.4, gap: [0.95, 1.30] },
  2: { spd: [272, 336], foldP: 0.62, foldMax: 2, alive: 6.6, gap: [0.80, 1.05] },
  3: { spd: [318, 392], foldP: 0.52, foldMax: 3, alive: 5.8, gap: [0.66, 0.90] }
};
G.TADPOLE = {
  segs: 7, segGap: 11, entryPad: 30, entryT: 0.26, entryBoost: 1.16,
  waveAmp: [2.5, 5.5], waveLen: [180, 280],   // 尾梢实测峰峰 9–14px（轻微摆动）
  foldDur: 0.22, foldSlow: 0.62,
  headPad: 1.50, tailPad: 1.3, foldPad: 1.15,
  invuln: 0.24,             // 重生间隔 = 阶段 gap；漏击回场 0.36–0.56s
  startle: 0.55, startleK: 1.24,
  countEval: 8, countAdd: 4, countDrop: 2, countMax: 3
};
```

调参建议：
- 想更"猫友好"：`foldP +0.1`、`spd ×0.9`、`headPad 1.7`。
- 想更"高手向"：`spd ×1.15`、`foldDur 0.18`、`countMax 4`（需同步 HUD 宽度）。
- 折返 +2 占比过高：提高 `foldP` 的代价是折返变多；应改为降低 `foldPad` 或缩短 `foldDur`。
