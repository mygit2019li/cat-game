# 逗猫猎场 · 游戏规则文档

> 适用版本：2026-10-24（微信小游戏 `minigame/`）
> 本文档整理当前线上逻辑的实际规则，与代码实现对齐；后续玩法调整请同步更新。

---

## 一、总览

- **玩法定位**：把手机平放，猫咪拍打屏幕捕捉猎物；主人负责选玩法、开局与复盘。
- **五种玩法**：深海捕鱼（fish）、蝴蝶花园（butterfly）、捕鼠行动（mouse）、激光暗室（laser）、暗夜萤光（pool，爬行虫）。
- **核心循环**：选玩法 →（多背景玩法先选背景）→ 倒计时开局 → 猫拍猎物得分 → 结算评级 → 可查看本周记录 / 好友排行 / 生成分享卡。

## 二、通用规则

### 1. 局时长
- 可选 **60 / 120 / 180 / 300 秒**（默认 180 秒）。
- **无限模式**：打开后倒计时只用于阶段推进，不减到 0、不自动结束，适合长时间给猫自玩。

### 2. 阶段推进（三阶段）
按本局已进行时间切分（`stageNow`）：
- **阶段①**：开局后前 20 秒（或局时长的 30%，取小值）
- **阶段②**：到 20 秒 + 50 秒（或局时长的 50%，取小值）为止
- **阶段③**：其余时间（终局，猎物最活跃）

阶段同时影响各玩法内部的行为节奏（见各玩法说明）。

### 3. 难度（三档）
| 难度 | 速度倍率 | 体型倍率 | 备注 |
|---|---|---|---|
| 轻松 easy | 0.65 | 1.3 | 猎物慢且大 |
| 标准 normal | 1.0 | 1.0 | 蝴蝶、老鼠额外 ×1.2 提速 |
| 激烈 hard | 1.5 | 0.85 | 蝴蝶、老鼠额外 ×1.25 提速 |

### 4. 猎物数量
- **单只 / 多只** 两档（默认多只=3 只同屏）。
- 多数玩法多只模式下同屏数量随阶段递增（如暗夜萤光：①3 → ②4 → ③5）。

### 5. 连击与失误（宽容连击机制）
- **拍中**：连击 +1，失误计数 −2（但不清零）。
- **拍在猎物附近没中**：连击**减半**，不清零。
- **拍空气**：连击不清零，失误计数 +1。
- **连击提难度**（与自适应辅助互斥，失误 ≥3 次时回落到基础档）：
  - 连击 ≥5：猎物速度 ×1.12（"猎物变敏捷了！"）
  - 连击 ≥10：速度 ×1.25、体型 ×0.92（"猎物越来越快！"）
  - 连击 ≥15：速度 ×1.45、体型 ×0.85（"极限追猎！"）
  - 连击 ≥5 后命中特效升级为大光爆。

### 6. 自适应辅助（可在设置开关）
连续拍空 ≥3 次后自动降档帮猫，分三级（missStreak ≥3 / ≥6 / ≥9）：
- 猎物变慢（最多 ×0.6）、体型变大（最多 ×1.55）、命中盒放大、自动放慢提示（"已自动放慢并放大猎物"等）。
- 连击恢复到 ≥3 后自动关闭。

### 7. 结算与社交
- 结算统计：命中数、准确率、最高连击，并给出**评级称号**（如"慵懒观察员"等，按成绩分档）。
- **本周记录**页查看历史局；**好友排行**按历史最佳展示。
- **分享卡**：可生成带评级与图片的分享内容，量词随玩法走：「我家猫 X 分钟抓了 Y 条小鱼 / Y 只蝴蝶 / Y 个光点，评级「Z」」。
  零命中的单局不写「抓了 0 只」，改成「一个XX都没抓到，全程当观众」；邀请好友的文案用跨玩法的「Y 个猎物」。

### 8. 其他设置
- **屏幕常亮**（默认开）：给猫玩时不自动锁屏。
- **系统防误触引导**（默认开）：首次进入弹引导。
- **音效 / 震动** 开关；**触摸采样抗抖**（anti-mistouch）。

## 三、各玩法规则

### 1. 深海捕鱼（fish）
鱼按三阶段改变巡游方式：
- **阶段①**：横向泳道直线巡游（轻微上下起伏）。
- **阶段②**：横向巡游 + 更大纵向摆动。
- **阶段③**：全向追踪航点游动（水草模式下 1/3 航点故意设在屏外，引诱鱼游出再游回）。

**品种与个性**（速度为基准倍率）：乌龟 0.5、河豚 0.55、鲸鱼 0.65、金鱼 0.7、神仙鱼 0.75、锦鲤 0.85、小丑鱼 1.0、鲨鱼 1.2（潜伏突进）、沙丁鱼 1.45（高频变向）。部分品种带 Peppy Cat 式行为节奏（忽快忽慢 / 突然转向 / 弹跳起伏 / 潜伏突进），整体游速已对齐旧版手感。冲刺（burst）触发时短促提速。

**双海域（开始前左右滑动选择，跨局记忆）**：
- **水草森林（kelp，默认）**：蓝色海水 + 绿水草丛；鱼从屏幕外游入、游出边界渐隐后再从别侧进入——"会进会出"的原版玩法。
- **泳池追鱼（pool）**：亮蓝池水 + 流动焦散光网 + 鱼身柔光；鱼**全程不出屏幕**——在屏内随机点淡入、航点永远在屏内、撞到屏幕边即调头。

### 2. 蝴蝶花园（butterfly）
- 七态状态机：扇翅飞行（FLAP）→ 滑翔（GLIDE）→ 降落（LANDING）→ 停留 → 起飞（TAKEOFF）→ 受惊（STARTLED）等。
- 停留时是最佳命中窗口；拍中未死会惊飞。
- **宽容判定**：命中盒外扩 1.7 倍（飞行目标容错更大）；半透明期（淡入淡出）命中阈值放宽。
- 从上/左/右三向飞入屏幕。

### 3. 捕鼠行动（mouse）
- 打地鼠式：两排共 **10 个洞口**，老鼠 peek（探头张望）→ dart（窜到邻洞）→ 缩回洞里。
- 探头时即可拍；窜洞途中也可截击（判定高度有限制）。
- 连续被拍的老鼠会"受惊"：探头间隔缩短、速度加快。
- **三套背景（左右滑动选择）**：室内房间（room，默认）/ 格子地毯（plaid）/ 霓虹格毯（neon，暗底 + 彩色光点 + 发光白鼠）。
- 霓虹等整屏铺满背景不生成窗/地毯；洞口全部保留。

### 4. 激光暗室（laser）
- 红色激光点两种状态循环：**dart 高速掠过**（沿航点直线 + 边界反弹）↔ **hold 停留**（主要命中窗口，原地小幅漂浮）。
- dart 途中概率**瞬移**到屏幕另一处（与其他光点保持距离）。
- 多只模式下同时出现多个光点（数量随阶段 3→5），落点互相避开 ≥150px。
- 多种激光配色变体（按权重随机），掠过留下灼痕轨迹。

### 5. 暗夜萤光（pool，爬行虫）
- 场景：Peppy Cat 式深棕灰石板墙 + 缓漂呼吸的环境萤尘（疏朗排布，避免密集）。
- **萤光小虫在石板地上爬行**（俯视视角）：
  - 造型：六足步足（三角架步态交替）、鞘翅 + 背中线、收拢膜翅（24Hz 颤动）、萌系大眼、腹尾"萤火"呼吸脉动、头朝爬行方向。
  - **两种走法（出生随机各半）**：
    - **直线虫**：笔直爬行，撞到屏幕边才像台球一样反射转向，停驻后保持原方向。
    - **蛇行虫**：左右微摆 S 形爬行，接近边界主动折返，停驻后随机换向。
  - 节奏：**爬行 → 停驻（主要命中窗口，显示命中圈）→ 原地转向再爬**；爬速按阶段约 195 → 267 → 339 px/s。
  - 停驻时长约为命中窗口的 1.5 倍宽松期。
- **活动范围**：整屏任意位置（仅留 26px 防裁切边距），不出屏幕、**不瞬移、不突然消失**；被拍中则爆成发光星星（光斑四溅 + 双层冲击环 + 闪白）后从别处淡入重生。
- **同伴避让**：多只模式下虫子间距小于约 115px 时平滑转向让开；停驻被逼近时缓慢挪开，不会叠在一起。
- 爬行沿途留下淡淡的荧光足迹；连击 ≥5 时虫身高频颤动（紧张感）。

## 四、命中与判定细则

- 命中判定以各猎物**可见包围盒**为准（`hittable`），多数玩法外扩系数 1（蝴蝶 1.7）。
- 淡入淡出期间（透明度过低）不可命中：鱼/蝴蝶 0.25、其他 0.4。
- 老鼠只在探头/窜洞状态、且未完全缩回洞内时可命中。
- 命中反馈：音效 + 震动（可关）+ 该玩法专属粒子特效 + 飘字。

## 五、防呆与合规

- 局时长、玩法 key 等本地存储字段有白名单收敛，脏数据自动回落默认值，不会闪退。
- 局内日志/记录读取做了健壮性兜底（坏 JSON、null 元素等）。
- 底部常驻适龄提示、健康忠告与免责声明（自动折行适配屏幕）。
