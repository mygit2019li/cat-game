# 逗猫猎场 · 游戏规则文档

> 适用版本：2026-10-24（微信小游戏 `minigame/`）
> 本文档整理当前线上逻辑的实际规则，与代码实现对齐；后续玩法调整请同步更新。

---

## 一、总览

- **玩法定位**：把手机平放，猫咪拍打屏幕捕捉猎物；主人负责选玩法、开局与复盘。
- **六种玩法**：深海捕鱼（fish）、蝴蝶花园（butterfly）、捕鼠行动（mouse）、激光暗室（laser）、暗夜萤光（pool，三种发光玩具动物：小狗 / 老鼠 / 瓢虫）、青蛙跳（frog）。
- **核心循环**：选玩法 →（多背景玩法先选背景）→ 倒计时开局 → 猫拍猎物得分 → 结算评级 → 可查看本周记录 / 好友排行 / 生成分享卡。

## 二、通用规则

### 1. 局时长
- 可选 **60 / 120 / 180 / 300 秒**（默认 180 秒）。
- **无限模式**：打开后倒计时只用于阶段推进，不减到 0、不自动结束，适合长时间给猫自玩。

### 2. 阶段推进（三阶段）
按本局已进行时间切分（`stageNow`）：
- **阶段①**：开局后前 20 秒（或局时长的 30%，取小值）
- **阶段②**：到 20 秒 + 50 秒（或局时长的 50%，取小值）为止
- **阶段③**：其余时间（终局，猎物最活跃）

阶段同时影响各玩法内部的行为节奏（见各玩法说明）。

### 3. 难度（三档）
| 难度 | 速度倍率 | 体型倍率 | 备注 |
|---|---|---|---|
| 轻松 easy | 0.65 | 1.3 | 猎物慢且大 |
| 标准 normal | 1.0 | 1.0 | 蝴蝶、老鼠额外 ×1.2 提速 |
| 激烈 hard | 1.5 | 0.85 | 蝴蝶、老鼠额外 ×1.25 提速 |

### 4. 猎物数量
- **单只 / 多只** 两档（默认多只=3 只同屏）。
- 多数玩法多只模式下同屏数量随阶段递增（如暗夜萤光：①3 → ②4 → ③5）。

### 5. 连击与失误（宽容连击机制）
- **拍中**：连击 +1，失误计数 −2（但不清零）。
- **拍在猎物附近没中**：连击**减半**，不清零。
- **拍空气**：连击不清零，失误计数 +1。
- **连击提难度**（与自适应辅助互斥，失误 ≥3 次时回落到基础档）：
  - 连击 ≥5：猎物速度 ×1.12（"猎物变敏捷了！"）
  - 连击 ≥10：速度 ×1.25、体型 ×0.92（"猎物越来越快！"）
  - 连击 ≥15：速度 ×1.45、体型 ×0.85（"极限追猎！"）
  - 连击 ≥5 后命中特效升级为大光爆。

### 6. 自适应辅助（可在设置开关）
连续拍空 ≥3 次后自动降档帮猫，分三级（missStreak ≥3 / ≥6 / ≥9）：
- 猎物变慢（最多 ×0.6）、体型变大（最多 ×1.55）、命中盒放大、自动放慢提示（"已自动放慢并放大猎物"等）。
- 连击恢复到 ≥3 后自动关闭。

### 7. 结算与社交
- 结算统计：命中数、准确率、最高连击，并给出**评级称号**（如"慵懒观察员"等，按成绩分档）。
- **本周记录**、**好友排行**都以**弹窗**形式弹出（背后是首页 + 遮罩，不占满屏）：
  面板从 0.94 缩放到 1 并上浮淡入（260ms），关闭时反向缩放淡出（200ms），
  右上角 ✕ 或点弹窗外任意处关闭，动画期间不接受点击。
  - 本周记录：**只保留最近 7 天、最多 200 条**（写入时裁剪，读取时也按天过滤）；面板高度按条数自适应，超过一屏改为**上下拖动滚动**（带惯性、右侧滚动条、上下渐隐），底部显示“上下拖动查看更多 + 当前 x–y / 总数”；横屏自动切**双列**（一屏 8 条）。
  - 好友排行：列表由开放数据域绘制在弹窗内的一块矩形里，展开动画结束后才显示，开始关闭时立即隐藏。
    - **需要 scope.WxFriendInteraction 授权**（读好友成绩的官方前提）：点入口时在同一手势里 `wx.authorize`；
      从没问过才弹窗，**拒绝过一次就不再反复弹**（改用「去设置开启」走 `wx.openSetting`）。
    - 四种态各有明确文案：已授权=出榜；请求中=「正在请求好友权限…」；已拒绝=「还看不到好友成绩」+ 去设置按钮；
      拉取失败（子域兜底）=「没能读取好友成绩」。**绝不把"没权限"显示成"好友里还没有成绩"**。
    - 榜里**永远有自己的那一行**（好友榜没返回自己时补一行），空榜时至少能看到「我的最好成绩」，不会整块空白。
    - 老基础库若返回 invalid scope（不认识这个授权），按"可用"处理，不能误判成用户拒绝。
- **分享卡**：可生成带评级与图片的分享内容，量词随玩法走：「我家猫 X 分钟抓了 Y 条小鱼 / Y 只蝴蝶 / Y 个光点，评级「Z」」。
  零命中的单局不写「抓了 0 只」，改成「一个XX都没抓到，全程当观众」；邀请好友的文案用跨玩法的「Y 个猎物」。

### 8. 其他设置
- 入口在**首页左上角的小齿轮**；设置以**左上角抽屉**形式滑出（不占满屏，背后是真实首页），点右上角 ✕ 或抽屉外任意处关闭，选项点完即自动保存。
- 抽屉有进出场动画：打开 240ms 从左上角滑入，关闭 200ms 原路滑出并淡出，期间不接受点击。
- **屏幕常亮**（默认开）：给猫玩时不自动锁屏。
- **系统防误触引导**（默认开）：首次进入弹引导。
- **音效 / 震动** 开关；**触摸采样抗抖**（anti-mistouch）。

## 三、各玩法规则

### 1. 深海捕鱼（fish）
鱼按三阶段改变巡游方式：
- **阶段①**：横向泳道直线巡游（轻微上下起伏）。
- **阶段②**：横向巡游 + 更大纵向摆动。
- **阶段③**：全向追踪航点游动（水草模式下 1/3 航点故意设在屏外，引诱鱼游出再游回）。

**品种与个性**（速度为基准倍率）：乌龟 0.5、河豚 0.55、鲸鱼 0.65、金鱼 0.7、神仙鱼 0.75、锦鲤 0.85、小丑鱼 1.0、鲨鱼 1.2（潜伏突进）、沙丁鱼 1.45（高频变向）。部分品种带 Peppy Cat 式行为节奏（忽快忽慢 / 突然转向 / 弹跳起伏 / 潜伏突进），整体游速已对齐旧版手感。冲刺（burst）触发时短促提速。

**双海域（开始前左右滑动选择，跨局记忆）**：
- **水草森林（kelp，默认）**：蓝色海水 + 绿水草丛；鱼从屏幕外游入、游出边界渐隐后再从别侧进入——"会进会出"的原版玩法。
- **泳池追鱼（pool）**：亮蓝池水 + 流动焦散光网 + 鱼身柔光；鱼**全程不出屏幕**——在屏内随机点淡入、航点永远在屏内、撞到屏幕边即调头。

### 2. 蝴蝶花园（butterfly）
- 七态状态机：扇翅飞行（FLAP）→ 滑翔（GLIDE）→ 降落（LANDING）→ 停留 → 起飞（TAKEOFF）→ 受惊（STARTLED）等。
- 停留时是最佳命中窗口；拍中未死会惊飞。
- **宽容判定**：命中盒外扩 1.7 倍（飞行目标容错更大）；半透明期（淡入淡出）命中阈值放宽。
- 从上/左/右三向飞入屏幕。

### 3. 捕鼠行动（mouse）
- 打地鼠式：两排共 **10 个洞口**，老鼠 peek（探头张望）→ dart（窜到邻洞）→ 缩回洞里。
- 探头时即可拍；窜洞途中也可截击（判定高度有限制）。
- 连续被拍的老鼠会"受惊"：探头间隔缩短、速度加快。
- **三套背景（左右滑动选择）**：室内房间（room，默认）/ 格子地毯（plaid）/ 霓虹格毯（neon，暗底 + 彩色光点 + 发光白鼠）。
- 霓虹等整屏铺满背景不生成窗/地毯；洞口全部保留。

### 4. 激光暗室（laser）
- 红色激光点两种状态循环：**dart 高速掠过**（沿航点直线 + 边界反弹）↔ **hold 停留**（主要命中窗口，原地小幅漂浮）。
- dart 途中概率**瞬移**到屏幕另一处（与其他光点保持距离）。
- 多只模式下同时出现多个光点（数量随阶段 3→5），落点互相避开 ≥150px。
- 多种激光配色变体（按权重随机），掠过留下灼痕轨迹。

### 5. 暗夜萤光（pool，三种发光玩具动物）
> 造型取自 **Peppy Cat 底部玩具栏的三个图标**（小狗 / 老鼠 / 瓢虫），动作、音效、特效对齐 **23.9s 猫玩平板视频**。
> 此前从模糊视频推断的「玫红圆盘虫 / 黄身蓝尾虫 / 彩虹软虫」已全部替换。

- **场景两套**（按截图）：
  | | 背景 | 出处 |
  |---|---|---|
  | 主题 0 | 暗棕紫地面 + 稀疏干草秆 + 碎石草屑 + 四周压暗 | 截图 1、2 |
  | 主题 1 | **深蓝龟裂多边形地面**（深蓝底 + 亮蓝细裂纹） | 截图 3 |
  - 草/裂纹一次性画进离屏 canvas 缓存；约开局 16 秒由 `G.poolShiftTheme()` 满屏金色火花 → 1.1s 交叉淡入换到主题 1。

- **三种动物**（配置在 `G.FF_TOYS`，出生随机抽取：权重各 1 → 约 1/3；被拍重生时换一种）：

  | | 名称 | 造型（按参考图） | 取样配色 |
  |---|---|---|---|
  | ① | **萤光小狗** `dog` | 圆头 + 两只不对称耳朵（左耳下垂、右耳支起，随步态摆动）、橙色口鼻 + 深橙鼻头 + 两颗白门牙、淡化的三角眉 | 主体黄 `#FDF000→#FFD200→#FF9800`；口鼻 `#FFC258→#FF9100→#EF7800`；鼻头/眉 `#E06A00`；眼 `#8A3B06`；牙 `#FFFDF2` |
  | ② | **萤光老鼠** `mouse` | 水滴形身体（顶部尖）、一对橙圆耳（会抽动）、尖嘴 + **青蓝鼻球**（带蓝光）、四只青蓝脚掌对角轮替抬起、身后拖一根逗猫杆线 | 身体同上黄渐变；耳 `#FF9100` / 内 `#FFD84A`；鼻球与脚 `#0081FF`、`#00CAC8`；杆线 `#38E8F2→#00CAC8` |
  | ③ | **萤光瓢虫** `ladybug` | 圆盘被一条**斜向鞘缝**分成两片（右上橙帽 + 左下黄底橙点）、六条青蓝腿探出盘外、张翅时两片鞘翅沿法向分开、缝里露冷白翅膜 | 帽 `#FFB020→#FF9100→#EF7800`；底 `#FFEA00→#FFC800→#FFA800`；斑点 `#F58A00`；鞘缝 `rgba(190,92,10,.95)`；腿/帽沿亮点 `#5BE8FF`、`#37B6FF` |

  - 三者共用「扁平发光贴片 + 白面高光 + 冷色描边」的画法，光雾色温按物种分档：狗 `rgba(255,168,86)`、鼠 `rgba(255,206,74)`、瓢虫 `rgba(255,152,72)`。
  - **共同语言：金色五角星**。身后拖的是一串小星星（不是圆形火星），命中散落的也是小星星。

- **物种动作差异**（`G.FF_TOYS` 的倍率，乘在下面的公共步态之上）：

  | key | 速度倍率 | 急爬概率偏移 | 换挡相位 | 张翅频率 | 体型 |
  |---|---|---|---|---|---|
  | `dog` | 0.94 | −0.06 | 1.15 | 1.25 | 1.06 |
  | `mouse` | 1.12 | +0.10 | 0.92 | 0.95 | 0.98 |
  | `ladybug` | 0.86 | −0.02 | 0.80 | 0.70 | 0.92 |

  即：老鼠跑得最快、最爱突然加速；小狗慢一档但耳朵/呼吸动得最频繁；瓢虫最沉、鞘翅张得最少。

- **命中**：一拍即灭（0.08s 收光）→ 13–18 颗主色碎光 + 4–7 颗冷色点 + 3–5 颗金色小星星 + 一圈很细的暖环 + 轻微闪白；
  爆散配色按物种走（`FF_POP_COLORS` / `POOL_SPARK`）：狗琥珀 `#ffd79a` + 冷绿松石 `#8ff0e6`、鼠柠檬 `#fdf3a8` + 天蓝 `#7fd8ff`、瓢虫橙 `#ffbe7a` + 薄荷 `#9ef0e0`；
  飘字「光爆 +1 / +2」，干地不画水面涟漪。

- **运动：两档步态**（视频实测帧速度中位 18% 屏宽/秒、90 分位 53%/秒、段落内方差 2.1 → 走走停停）：
  | 阶段 | 慢爬 | 急爬 | 换挡周期 | 急爬占比 |
  |---|---|---|---|---|
  | ① | 58 px/s | 150 px/s | 0.55–1.2s | 35% |
  | ② | 70 px/s | 190 px/s | 0.45–1.0s | 45% |
  | ③ | 84 px/s | 230 px/s | 0.36–0.85s | 55% |
  - 速度平滑 0.15s 到位（不瞬移，但有"突然加速"的急爬感）；换挡时航向随机偏 ±0.55rad（像小动物临时拐弯）。
  - **身体朝向固定朝上不旋转**（视频里轮廓始终是正的，只平移）；贴边先软推、真贴上再镜像反弹。
- **换位**：自发换位很罕见——**9–13 / 7–10 / 5–8 秒**一次，0.18s 暗下去 → 至少隔 42% 短边 → 0.26s 亮起。
- **同伴避让**：间距小于约 96px 时轻柔推离；连击 ≥5 时光晕更大并轻微颤动（纯光效，不加难度）。
- **动作节奏（对齐视频 9 段出现）**：被拍中 0.08s 收光 → **暗场 0.12–0.55s** → 换到别处 0.26s 淡入；
  视频里各段间隔 0.1–1.7s，不是"拍完立刻原地出现"。亮起时播 `firefly-spawn.wav`。
- **音效共七段**（均由 `tools/gen_firefly_sfx.py` 按视频音轨实测参数合成，22.05kHz 单声道 wav）：
  视频里命中那一下不是低沉水泡声——onset 的频谱重心实测落在 **0.72–1.79kHz**、衰减 40–190ms，所以三种动物各占一段，从低到高排开。

  | 文件 | 触发 | 实测/合成依据 |
  |---|---|---|
  | `firefly-hit.wav` | 拍中（通用回退） | 频谱重心 0.99kHz、衰减 28ms（成品 1053Hz / 0.19s） |
  | `firefly-hit-dog.wav` | 拍中小狗 | 主体 1000Hz 衰减 30ms + **180→130Hz 下滑「汪」低频垫底**（成品重心 798Hz，偏沉） |
  | `firefly-hit-mouse.wav` | 拍中老鼠 | 主体提到 1300Hz 衰减 26ms + **2600Hz 高斯窗短吱**（成品重心 1531Hz） |
  | `firefly-hit-ladybug.wav` | 拍中瓢虫 | 主体 1750Hz 衰减 18ms（更脆）+ **2.6–5.2kHz 带通噪声翅膜嗡**（成品重心 1892Hz，在实测带上沿之外，为的是和老鼠拉开） |
  | `firefly-flare.wav` | 鞘翅张开 | 极轻 1.6–3.6kHz 摩擦（成品重心 2646Hz，音量 0.16） |
  | `firefly-spawn.wav` | 出现/重生 | 1.9–3.3s 与 4.6–4.9s 里一串 ~1kHz 小 ticks（成品 8 声 / 0.42s，重心 1321Hz） |
  | `firefly-shift.wav` | 换关 | 0.85s 柔和高亮 shimmer（成品重心 3450Hz，配满屏金色火花） |

  限流：拍中 70ms、张翅 900ms、出现 260ms；满屏 5 只也不叠成噪音。
  没有音频能力的机型回退到 `tone()` 合成，同样按物种换中心频率（狗 780/520、鼠 1300/980、瓢虫 1720/1240）。

### 6. 青蛙跳（frog）
- 场景：夏夜荷塘，6 片荷叶按 3×2 分布，青蛙在荷叶之间跳跃（不瞬移、不突然消失，位置变化全部由可见跳跃完成）。
- **四态循环**（标准难度约 2.5 秒一轮，循环结束换一片荷叶）：
  | 状态 | 时长 | 表现 | 得分 |
  |---|---|---|---|
  | 蓄力 CROUCH | 0.55s | 蹲低、后腿压扁、鸣囊鼓起；**最后 0.35s 目标荷叶点亮金色光圈** | +1 |
  | 腾空 LEAP | 0.75s | 抛物线跨过水面，最高点离水面约 66px，水面投影与身体分离 | **+2（空中截击）** |
  | 落水 LAND | 0.28s | 压扁回弹 + 水花 + 涟漪，荷叶下沉晃动 | +1（判定放宽到 25%） |
  | 静坐 SETTLE | 0.90s | 呼吸起伏、随机蛙鸣、荷叶上小幅挪动 | +1 |
- **落点预兆**：起跳前 0.35s 目标荷叶亮起虚线金圈——这是猫唯一的预判依据，三个段位都保留。
- **阶段差异**：
  | 阶段 | 同屏青蛙 | 蓄力 | 静坐 | 跳跃特征 |
  |---|---|---|---|---|
  | ① | 3 | 0.60s | 1.00s | 只挑最近的荷叶（短弧线） |
  | ② | 4 | 0.52s | 0.80s | 任意荷叶，落点全随机 |
  | ③ | 5 | 0.44s | 0.62s | **连跳：落地几乎不停顿再跳一次，一组最多 2 跳**（第二跳必跨远） |
- **同屏约束**：每只青蛙独占一片荷叶，落点计算排除其他青蛙所在叶；同屏上限受荷叶数封顶（6 片留 1 片空叶）。
- **命中判定**：可见包围盒 ×1.15（落水瞬间 ×1.25）；腾空时水面投影同样可命中（不要求精确压在抛起的身体上）。
- **发光**：青蛙自带黄绿光晕（全场最亮元素，猫好锁定）；**腾空时光晕放大 1.35 倍、亮度 ×1.6**，兼作 +2 窗口提示。
- **命中特效**：拍中「啪」地炸开——细短草屑四散 + 小光点 + 上飘萤火 + 贴水面的椭圆冲击波 + 荷叶涟漪；空中截击改为空中正圆爆开 + 落点补一圈水波，飘字「空中截击 +2」。
- **被拍后**：淡出 → 0.9 秒后从另一片荷叶的水波中重生。
- 难度、连击提速、自适应辅助统一作用于「蓄力 + 腾空 + 落水 + 静坐」时长（等效速度），无需单独适配。

## 四、命中与判定细则

- 命中判定以各猎物**可见包围盒**为准（`hittable`），多数玩法外扩系数 1（蝴蝶 1.7）。
