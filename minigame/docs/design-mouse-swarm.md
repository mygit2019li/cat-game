# 群鼠场景重设计 · 角色造型 + 背景环境

> 适用玩法：小鼠迷宫（原「群鼠乱窜」swarm 场景，俯视满屏乱窜）
> 设计目标：群体规模 6 只、每只差异化（体型/毛色/配饰/姿态）体现性格层次；
> 背景构建贴合鼠类习性的「废弃粮仓」环境（道具/光影/空间层次）；
> 输出风格说明、色彩基调、角色与环境融合建议，保证视觉统一 + 故事感。
>
> 技术前提（现有管线，设计必须贴合）：
> - 角色由 `js/draw.js` 的 `D.mouse(ctx, p, t)` 用 Canvas 2D **矢量**绘制（侧视瘦长鼠形），花色/体型/速度走 `G.MOUSE_VARIANTS`（config.js:563，现 3 只）。
> - 场景地板由 `js/scenery.js` 的 `drawSwarmFloor` 绘制（现为深绿灰渐变 + 随机暗斑的抽象石地，无具象环境）。
> - 群体数量走 `preyCount`（现 1/3 两档，config.js:234）。
> - 整体美术语言：扁平卡通矢量、低饱和自然色、深色底压暗让主体跳出。

---

## 一、风格说明

**整体定位：卡通矢量 · 微写实肌理（cartoon-vector, subtle-illustrated）**

- 沿用项目既有的扁平卡通矢量风格（与鱼/蝴蝶/青蛙/猫一致），**不转写实、不转像素**——像素会破坏与其余三个玩法的统一感，写实会拉高单帧绘制成本且与猫咪的扁平造型冲突。
- 在「卡通剪影 + 柔和渐变」骨架上，给老鼠加一层**微写实细节**：背毛流、腹光、耳廓内粉、尾环节、胡须——现有 `D.mouse` 已做到这一层，重设计是在此之上**做角色性格分化**，而非推翻画法。
- 背景从「抽象石地」升级为**可识别的废弃粮仓俯视图**：用色块分层 + 少量道具剪影 + 暖光晕，保持矢量可绘制、可离屏缓存（与 `groundCache` 机制一致）。

**一句话风格锚点**：
> 像绘本里的"偷粮夜"——暖黄仓顶灯从上方洒下，一群毛色各异的小鼠在木屑与碎粮间钻来钻去，画面干净但有故事。

## 二、角色设计（6 只 · 性格层次）

群体规模定 **6 只**（落在 5–10 区间中位，俯视满屏乱窜下 6 只密度刚好不挤、性能稳）。
6 只按「体型 大/中/小 × 毛色 深/中/浅 × 配饰 × 姿态/速度」四个维度分化，
形成一个**有老有小、有莽有怂**的鼠群，性格一眼可辨。

### 角色表

| # | 代号/昵称 | 体型 size | 速度 speed | 毛色基调（back/mid/belly） | 配饰（accessory） | 姿态/性格 | 在群里的"戏" |
|---|---|---|---|---|---|---|---|
| 1 | **老仓（仓头儿）** | 1.18（大） | 0.88（慢） | 暖棕：`#7a6450`/`#9c8468`/`#e2d3ba` | 头顶一小撮翘毛 + 颈圈旧皮绳 | 昂首阔步、尾拖长 | 群头，动作沉稳带节奏，最后才窜进洞 |
| 2 | **炭胆（莽夫）** | 1.05 | 1.32（快） | 炭黑：`#3f3b37`/`#5f5952`/`#9d968a` | 左耳一道浅色"疤"（V 形刻痕） | 弓背冲劲、尾直甩 | 冲最前、抢食最凶，被拍概率最高 |

### 分化维度落地（怎么接现有代码）

现有 `MOUSE_VARIANTS` 每项已有 `speed/size/back/mid/belly/ear/earIn/tail/...`。
重设计**只加字段、不改结构**：

1. **体型/速度/毛色**：`size`、`speed`、`back/mid/belly` 直接按上表填 6 项（现 3 项扩为 6 项）。
2. **配饰**：新增可选字段，`D.mouse` 末尾按存在与否绘制：
   - `accessory: "topknot"`（老仓头顶翘毛）/ `"scar"`（炭胆耳疤）/ `"collar"`（老仓颈绳）/ `"spine"`（花栗脊纹）/ `"whiteTip"`（烟尾尾尖白）/ 无。
   - 配饰用 `ctx` 少量 path 绘制，颜色取自该变体 `back/mid`，不引入新色板。
3. **姿态/性格**：由 `speed` + 新增 `gait`（`"stride"|"dash"|"slink"|"weave"`）驱动 `prey.js` 的 `updateSwarmMouse`：
   - `stride`（老仓）：步频低、尾摆幅大；`dash`（炭胆）：步频最高、方向更直；
   - `slink`（霜尖/灰仔）：贴边概率高、停顿嗅闻多；`weave`（花栗）：转向频率高、走 S。
   - 实现上只需在转向/贴边/停顿逻辑里按 `gait` 调权重，不重写状态机。
4. **个体唯一性**：spawn 时把 6 个变体**不重复分配**给 6 只（现是随机重复取），保证一屏 6 只各不相同、性格齐全。

### 性格层次的视觉读法（给策划/美术的对照）

- **大 = 稳**：老仓、炭胆体型大，在俯视图里占屏大、慢 → 读作"老大/莽汉"。
- **小 = 灵**：霜尖、灰仔体型小、贴边多 → 读作"小机灵/幼崽"。
- **配饰 = 记忆点**：6 只里只有 4 只有配饰，且各不重复，扫一眼就能数清"哪只是哪只"。
- **颜色 = 冷暖分组**：暖棕系（老仓/花栗/灰仔）vs 冷灰紫系（炭胆/烟尾/霜尖白）→ 画面里自然分出两拨，不单调。

## 三、背景设计（废弃粮仓 · 俯视）

选**废弃粮仓**作为主环境（在"粮仓/地下管道/废弃仓库"三选一里，粮仓最贴"鼠群 + 偷粮"故事，且俯视构图最易做空间层次）。

### 构图与空间层次（俯视，由远及近 4 层）

```
┌─────────────────────────────────────────────┐
│  L4 暗角/顶光晕（压四周、提中间，HUD 可读）   │
│  ┌─────────────────────────────────────────┐ │
│  │ L3 道具层：粮袋/木箱/麻袋/散落碎粮/木屑  │ │  ← 可被鼠"蹭过/绕开"
│  │   ●粮袋   ▢木箱   ···木屑  ✳碎粮粒      │ │
│  │        ~~~ 鼠群活动区（中央亮）          │ │
│  │  ▢      ~  鼠  ~      ●     ▢           │ │
│  └─────────────────────────────────────────┘ │
│  L2 地面层：木地板（横向木板缝 + 磨损色斑）  │
│  L1 底：深暖棕黑（#2a2118 系）               │
└─────────────────────────────────────────────┘
```

1. **L1 底色**：深暖棕黑 `#241c14 → #1a140d`（竖向渐变，比现 swarm 的绿灰更"仓库夜"）。
2. **L2 木地板**：横向木板条（间距随 H 自适应），板缝用更暗的 1px 线 + 少量横向磨损高光；板与板间色阶微差（±4% 亮度）避免死板。离屏缓存一次（走 `groundCache`），运行时只 `drawImage`。
3. **L3 道具层**（稀疏，6–9 件，不挡鼠）：
   - **粮袋**（麻袋剪影，圆头方身 + 袋口扎绳，暖褐 `#6b5638`）×2–3，放四角偏内。
   - **木箱**（方框 + 斜撑，`#4a3a28` 描边）×2，放边沿。
   - **散落碎粮/木屑**：30–50 个 2–4px 暖点（`#8a6f4a`，alpha .2–.5）随机撒在中下部，制造"被啃过"的痕迹。
   - **木屑条**：10–16 条 8–18px 短弧线（`rgba(150,120,80,.25)`），沿地板缝方向，强化俯视木纹。
   - 道具都画在**地板之上、鼠之下**，鼠从道具上穿过时自然形成"前景/遮挡"暗示（道具在鼠"脚下"）。
4. **L4 光影层**：
   - **顶光晕**：中央偏上画一个大的暖色径向光（`rgba(210,170,100,.10) → 0`），模拟"仓顶灯"洒下，让中央鼠群活动区最亮。
   - **顶部压暗**：顶部 30% 高度叠 `rgba(0,0,0,.45)→0` 渐变（保留 HUD 可读，沿用现 `drawSwarmFloor` 的压暗思路）。
   - **四周暗角**：径向暗角 `rgba(0,0,0,.4)`（沿用现有 vignette）。
   - 可选**光束**：从顶光晕往下 2 道极淡的斜向暖光带（`rgba(200,160,90,.05)`），增加"夜里有光"的故事感，不抢主体。

### 色彩基调

- **主色**：暖棕黑（地板/底色）——仓库夜的"暖暗"。
- **辅色**：暖褐/麦黄（道具、碎粮、顶光）——"粮食"主题色，给画面唯一的暖光源。
- **角色色**：6 只鼠的毛色是**全场唯一的中高饱和区**（暖棕系 + 冷灰紫系），在暖暗背景上自然跳出。
- **对比策略**：背景整体压到亮度中位数 < 35（与项目"深色底让主体跳出"的一致做法），鼠的 belly/sheen 保留高光 → 鼠永远是视觉焦点。
- **不要出现**：冷绿（现 swarm 的绿灰底弃用）、高饱和红蓝、写实阴影贴图——保持扁平卡通。

### 与玩法的融合

- **无洞口**（swarm 是满屏乱窜，不靠洞），但保留"碎粮热点"：某片碎粮密度高的地方，鼠会短暂聚集（可选增强，增加"它们在抢粮"的叙事）。
- 道具**纯装饰、不阻挡碰撞**（俯视装饰层），鼠从上面穿过即可，不影响现有 `updateSwarmMouse` 的边界/转向逻辑。
- 道具位置在场景 `setup` 时随 `swarmSpots` 一起随机生成并缓存，避免每帧重算。

## 四、角色 × 环境 融合建议

1. **接地阴影**：每只鼠在脚下加一个扁平椭圆软阴影（`rgba(0,0,0,.28)`，宽=鼠宽 0.8、高=鼠宽 0.22，随 size 缩放），让鼠"落在地板上"而非漂着。这是俯视场景立体感的关键，现有 swarm 俯视缺这一步。
2. **色彩回声**：鼠的 belly/sheen 暖色（白/浅棕）与背景顶光晕、碎粮同属暖系 → 鼠受光方向与"仓顶灯"一致（上方受光），光向统一。
3. **尺度锚定**：道具（粮袋/木箱）尺寸约为鼠的 2–3 倍，给玩家"鼠很小、环境很大"的尺度感，强化"偷粮夜"的弱小感与故事性。
4. **动线引导**：顶光晕中心 = 鼠群活动最密集区 = 玩家点击热区，视觉焦点与交互焦点合一。
5. **性能**：地板 + 道具 + 光晕全部**离屏缓存**（`groundCache["swarm"]`），运行时 `drawImage` 一次；只有鼠和碎粮微动是逐帧绘制，6 只矢量鼠 + 几十粒碎粮，单帧成本可控。
