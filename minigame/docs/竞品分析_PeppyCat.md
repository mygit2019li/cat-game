# 竞品分析：Peppy Cat（逗猫 app）

> 数据来源：App Store 商品页与用户评论（中国区 / 国际区）、Sensor Tower 概览页、第三方 App 数据站（apprank / marlvel）。
> 说明：本文中「据评论推断」为未见官方披露、由用户反馈反推的判断；收入与下载为第三方估算，非官方数据。

---

## 0. 一句话结论

Peppy Cat 是这个品类的「基准答案」：**规则极简到几乎没有规则（无分数、无等级、无计时、无记录），把所有资源砸在玩具素材与音效上**，靠订阅 + 广告变现。它证明了「评分/等级/记录」不是这个品类的刚需，也暴露了广告过载与多点触控缺失两个致命弱点——这两点恰好是你产品的机会位。

## 2. 游戏规则拆解

| 维度 | Peppy Cat 的做法 | 备注 |
|---|---|---|
| 核心循环 | **无尽的连续循环**（endless loop），没有「局」的概念 | 官方描述原文："a clever endless loop" |
| 计时 | **没有计时器，也不自动结束** | 第三方分析站明确写「excludes third-party advertisements and **timed sessions**」 |
| 计分 / 评级 | **没有分数、没有评级、没有统计** | 猫拍到目标只是「消失/变形 + 轻音效」 |
| 等级 / 成长 | **完全没有** | 无档案、无成就、无记录 |
| 目标种类 | 6 种：老鼠、蝴蝶、七星瓢虫、鱼、激光笔、兔子（新版本陆续加新玩具） | 每个场景「动态逻辑都有区别」 |
| 难度 | **没有难度档** | 目标速度固定，靠玩家（猫）自己适应 |
| 目标数量 | 设置里唯一的调节项：**选择玩具数量** | 与我们「单只/多只」同构 |
| 视听 | 按猫/狗视觉光谱选色（高对比、避开猫不敏感的红）；玩具行为与音效被刻意调成「挑逗」 | 这是他们真正下功夫的地方 |
| 屏幕 | 支持横竖屏自由切换、全屏沉浸（无状态栏遮挡） | 我们强制横屏（对猫更合理） |
| 触摸 | **只支持单点触控**（用户明确吐槽：猫碰到屏幕其他地方就按不到鱼） | 见 §5，这是最大缺陷 |
| 设置项数量 | 1 项（玩具数量） | 我们 8 项，差别很大 |
| 包体 | 191–252MB | 几乎全是素材 |

### 与我们当前版本的对比

| 维度 | Peppy Cat | 逗猫猎场（我们） | 判断 |
|---|---|---|---|
| 局结构 | 无尽循环，无局 | 60/180/300s + 无限 | 他们更彻底；但我们有「局」才有统计与分享素材 |
| 分数/评级 | 无 | 有（hpm 四档） | **他们无也能拿 4.5–4.9 分**，说明这不是刚需 |
| 记录/排行 | 无 | 周记录 + 好友排行 | 我们的重投入项，需重新评估 ROI |
| 玩法数 | 6 种玩具 | 6 种玩法（各自独立状态机） | 平手，但我们的状态机更复杂 |
| 素材质感 | 251MB 实拍级素材 | 程序化矢量绘制，≤4MB | **劣势**（包体限制决定的） |
| 多点触控 | **不支持**（被骂） | **同样不支持**（见 §6） | 修掉即领先 |
| 广告位置 | 免费版广告密集，评论大量差评 | 尚未接入 | 我们有机会做成差异点 |
| 分享/传播 | 无任何分享 | 图片分享卡 | 我们领先，但缺视频 |

## 3. 盈利手段拆解

### 3.1 订阅（主力）

| 方案 | 价格 | 权益 |
|---|---|---|
| 周订阅 | $1.99 | 去广告 + 解锁全部功能 |
| 月订阅 | $4.99 | 同上 |
| 年订阅 | $24.99 | 同上（折算 $2.08/月） |

国际版另有一次性档：Pro $4.99 / 「All you need for 1 year」$9.99 与 $19.99。

**定价逻辑**：周订阅 $1.99 是典型的「高 ARPU 短周期」打法——这个品类的使用周期本来就短（猫玩腻就走），所以用周订阅在最初两周把钱收完，而不是赌用户留一个月。年订阅 $24.99 只是价格锚点与心理参照。

### 3.2 广告（免费版）

据评论推断为**开屏/插屏为主**：
- 「点进去就是广告，不想有广告就花钱」
- 「全是广告，你点一下就是广告」
- 英文区：「Why is there ads for this app whose target audience is a literal animal? I love to tell my cat that I can't let her play yet because she needs to witness 5 minutes of unskippable ads first」
- 「This is manipulative and insulting marketing」

**这是明确的负面资产**：广告直接插在「猫要玩」的路径上，主人愤怒、评分被拉低。他们用广告做「逼订阅」的压力，短期收入有效，长期伤品牌。

### 3.3 商业表现（第三方估算，仅供参考）

- Sensor Tower（澳门区）：Top Free iPad 娱乐榜第 57、Top Grossing iPhone 娱乐榜第 122
- 上月估算：下载 5k–50k，**收入 < $5k**
- 上架 111 个国家，17 种语言，更新频率约 7–8 天一个版本（持续加玩具）

**这个数字很重要**：即便是这个品类的头部产品之一，单区月收入也在 5,000 美元以下量级。说明**逗猫 app 是一个小而美的细分市场，天花板不高**——凡是靠「广告展示次数 × eCPM」的收入模型，都必须靠规模（DAU）而不是靠单价。

### 3.4 他们没做的变现

- 没有电商/带货（同款玩具、猫粮分佣）
- 没有品牌联名场景
- 没有视频内容变现
- 没有 UGC 社区

这四条都是空位。

## 4. 用户评论里的真实痛点（比功能表更有用）

| 痛点 | 原话/表现 | 对我们的意义 |
|---|---|---|
| 广告过载 | 「全是广告」「点一下就是广告」「5 分钟无法跳过」 | 我们的「局内零广告」可以直接作为宣传点 |
| 不支持多点触控 | 「作者自己用猫试过吗？每次猫不能碰到屏幕其他地方，不然就按不了鱼」 | **我们也一样，见 §6（可立刻修）** |
| 猫一开始不感兴趣 | 「先用逗猫棒在屏幕旁引导几次，让猫发现移动目标」 | 需要「首次引导」设计（我们目前没有） |
| 设备被猫拍飞 | 「别放易碎桌面边缘，力气大的猫扑抓冲击力很强」 | 放置引导 + 防滑提示是低成本加分项 |
| 猫玩腻 | 「每个场景动态逻辑有区别，能延缓厌倦」 | 与我们的「内容轮换」判断一致 |

## 5. 五个值得借鉴的判断

1. **「没有局」是这个品类的正确形态**。他们连结束都不需要，因此永远不会卡在结算页——这与我上一版给你的「会话制」结论完全吻合，而且他们走得更彻底。我们保留「局」的价值只剩一个：产出可分享的素材单元。
2. **设置项要压到 1–2 个**。他们只有「玩具数量」。我们有 8 项设置（数量/难度/时长/音效/震动/辅助/常亮/防误触），对「没时间的主人」是纯负担。建议把难度、辅助、时长合并成「自动」，只留数量与音效。
3. **钱花在素材与音效上，不是规则上**。251MB 全砸在玩具与音效。我们受 4MB 包体限制，只能靠程序化动画弥补——所以差异化的战场不在「更复杂的规则」。
4. **周订阅的定价心机**：用 1.99/周在最初两周收完钱，承认「这个产品天然短命」。
5. **用「新玩具」做版本节奏**（7–8 天一个版本，每次加玩具），这是他们维持活跃度的主要手段，成本低、用户可感知。

## 6. 三个不要抄

1. **不要在猫的游玩路径上放广告**。他们的差评几乎全部来自这一条，而且这是「主人替猫付代价」的错位。
2. **不要用「逼订阅」当增长**。短期 ARPU 高，长期评分与口碑受损，且小游戏生态对差评的惩罚更直接。
3. **不要因为「规则简单」就省掉素材质量**。他们能赢在 251MB 素材上，我们省不掉这一课，只能用别的方式补（见下）。

## 7. 我们必须先修的一个 bug（顺手变成卖点）

我核对了代码：`game.js:685` 与 `:747` 都在取 `e.touches[0]` / `changedTouches[0]`——

```js
const tp = e.touches && e.touches[0] || e.changedTouches && e.changedTouches[0];
```

这意味着**猫第一只爪子按住屏幕时，第二只爪子按下的位置不会参与命中判定**（事件里 `touches[0]` 仍是第一只爪子）。这正是竞品被骂得最狠的那一条，而我们现在是一样的。

**修法**：改为遍历 `e.changedTouches`（本次新增的触点），逐个换算坐标并逐个判定命中；UI 按钮只取第一个。改动量小，收益是：

- 直接具备「双爪同时扑击」体验——这是猫最有代表性的动作
- 与上一版策略里的「双爪乱拍」高光检测天然同源（`300ms 内 ≥2 个不同触点`）
- 可以直接写进宣传语：「支持多点触控，猫的两只爪子都能拍到」

## 8. 对我们的三条动作建议（结合前两版文档）

| 优先 | 动作 | 依据 |
|---|---|---|
| **1** | 修多点触控 + 加「双爪乱拍」高光 | 竞品最痛的缺陷，我们成本最低，且直接服务视频素材 |
| **2** | 会话制（自动续局 / 无局感）+ 设置项压到 2 项 | 竞品的形态验证；我们的 8 项设置是反向操作 |
| **3** | 局内零广告 + 只卖素材（视频导出/场景皮肤） | 竞品差评全部来自广告位置，我们的差异点 |
| 附 | 首次引导（屏幕旁先放逗猫棒 / 屏内出现引导动画） | 评论里的真实门槛，我们目前完全没有 |

## 9. 一句话修正我之前的判断

上一份文档里我说「评级归一可以做，但降为 P2」。看到竞品数据后要再降一级：**评级、周记录、好友排行这三项，建议先砍到「只保留记录、不做评级」**——竞品用「零战绩」拿到 4.5 分，说明主人真正需要的是「猫在玩」，不是「猫考了多少分」。省下的开发时间应该给素材、录屏与会话机制。
