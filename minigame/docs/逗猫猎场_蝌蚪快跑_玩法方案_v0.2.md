## 1. 一句话定位

**「会逃跑的蝌蚪」**：猫一拍，它就加速逃窜、尾巴甩成一条线；猫学会预判逃跑方向后，在它换向的瞬间截住它。它补上现有六种玩法都缺的东西——**「拍击有因果」的追逐反射**：现在所有猎物都不理会猫的爪子，只有这只蝌蚪会「因为你拍它所以它跑」。

## 2. 为什么是「o------」这个造型

1. **自带“难/易”两档命中区**：头部小且会闪，尾节细长容易拍到——一个目标两种手感，不需要额外难度系统
2. **节体跟随是最便宜的“活物感”**：每节沿头部轨迹延迟跟随、正弦摆动，转向时整条尾巴甩出弧线，不要求逐帧美术
3. **视觉即判定**：判定盒按每节可见位置算，猫看到尾巴摆到哪就能拍到哪，不会“看着打到了但没中”

配色按猫视觉光谱（对齐现有玩法）：水面用亮黄绿/白腹高对比蝌蚪，轮廓加光晕。

## 3. 背景与切换（对齐捕鱼的交互模型）

### 3.1 专属背景：藕塘水底

| 项 | 设计 |
|---|---|
| 场景语言 | 俯视藕塘：淡青水色 + 藕叶圆盘 + 光柱焦散 + 水底细沙纹（复用泳池追鱼的焦散光网技术） |
| 猫视觉 | 水色与蝌蚪对比度最高（亮底深虫或深底亮虫两套背景正好互补） |
| 环境层 | 缓慢漂动的气泡/浮尘（复用现有 amb 粒子） |
| 蝌蚪层 | 走水面层绘制，藕叶只作背景装饰、不产生遮挡与消失 |

### 3.2 背景切换（照搬捕鱼标准交互）

- 开局前左右滑动 / 点按两侧翻页，跨局记忆 `bg_tadpole`
- 首发两套（保证“可切换”成立）：
  - **A 晨光浅塘**：亮青绿水 + 光柱，高亮度高对比（默认）
  - **B 暮色深塘**：深蓝紫水 + 水草剪影 + 萤光浮尘，低亮度高对比
- 后续加第三套零成本：机制与鱼完全一致，只加一组配色与装饰参数
- 命中特效随背景换色（复用 `SEA_THEMES.spark/ripple` 的做法）

## 4. 核心循环、造型与判定

### 4.1 状态机（四态）

```
WANDER 闲游 ──(拍击落点接近 / 命中)──▶ FLEE 逃窜
   ▲                                     │
   │(力竭)                               │(阶段③)
   │                                     ▼
TURN 换向 ◀──(到泳道尽头 / 撞边)── DART 疾冲
   │(0.25s 停顿：唯一静止窗口)
   └──▶ 回到 WANDER（沿新方向）
```

| 状态 | 时长（假设） | 表现 | 计分 |
|---|---|---|---|
| WANDER 闲游 | 2.0–3.5s | 慢速沿水道游，正弦起伏，尾节慢摆 ≈1.2Hz | 命中 +1 |
| FLEE 逃窜 | 1.2–2.0s | 速度 ×2.6，尾节快摆 ≈2.4Hz、摆幅加大，尾后水花尾迹 | 命中 +1 |
| DART 疾冲 | 0.8–1.2s | 直线冲刺穿过屏（阶段③才有），冲前 0.15s 压扁蓄力 | 命中 +1 |
| TURN 换向 | 0.25s | **原地调头**（身体弯成 C 形再弹直，借萤光的预告语言） | 命中 +1（最好拍的窗口） |

**逃跑的方向因果（灵魂规则）**：FLEE / DART 方向 = 远离最近一次拍击点（±20° 抖动）。拍它左边它往右跑——拍几次猫就会预判，「在它转弯的地方等它」的高级玩法由此成立。

与萤光走停节拍的关系：共用「调头=预告窗口」的语言，但**不做周期性停顿**——萤光=走走停停的爬虫，蝌蚪=永远在逃的泳者，性格分明。

### 4.2 命中判定（按已拍板：不分部位计分）

| 部位 | 判定 | 计分 | 命中后反应 |
|---|---|---|---|
| 头部 | 可见包围盒 ×1.15 | **+1** | 立即 FLEE，特效最强（金色爆） |
| 尾节（任一节） | 可见包围盒 ×1.35（尾巴细，放宽） | **+1** | 受惊甩尾 + 水花，**0.6s 判定无敌**（防一次扑击重复计数），随即 FLEE |

- 一次扑击只计一次命中（先碰到哪个部位都一样）
- 统计维度保留「头部命中占比」（埋点用），不影响分数与评级
- 拍尾巴同样是完整命中：猫每次拍击都有反馈，且蝌蚪会逃——「拍到了，但它跑了」的张力保留

### 4.3 消失与重生（沿用 4.6 边缘规则）

- 被拍中：水花 + 渐隐 0.22s（不瞬灭），暗场 0.3–0.8s
- 重生：**只从屏幕边缘游入**（左右边为主，朝向屏内 ±25°），入场首段闲游 ×1.15——与萤光同一套「绝不屏内凭空出现」

## 5. 数量：按击中能力动态调节（1–7，已拍板）

不做固定档位。规则：

| 参数 | 值（假设） |
|---|---|
| 评估周期 | 每 8 秒评一次 |
| 加 1 只条件 | 上一周期命中 ≥4 次 |
| 减 1 只条件 | 上一周期命中 ≤1 次，**连续两个周期才减**（防抖） |
| 范围 | 最少 1 只，最多 7 只 |
| 起始 | 1 只 |
| 新增个体 | 从屏幕边缘游入（同一套进场规则） |
| 与自适应的关系 | 自适应辅助生效期间**冻结加档**、优先减档 |

- 设置里的「单只 / 多只」在该玩法下**不生效**（UI 隐藏该行或置灰，口径写入 PRD 6.2/8.1）
- 动态数量的产品意义：数量本身就是难度旋钮——猫打得好，场面变热闹（正反馈）；打不动，场面变简单（不挫败）。这比固定 3→5→7 更贴合「猫的个体差异大」这一现实
- 性能上限：7 只 ×（1 头 + 5 尾）= 42 个矢量绘制单元，可承受

## 6. 难度与阶段

| 阶段 | 时间（1 分钟局） | 行为配比 |
|---|---|---|
| ① 闲游期 | 0–18s | WANDER 为主，FLEE 少（建立信心） |
| ② 疾游期 | 18–33s | FLEE 频率 ×1.6，速度 ×1.15 |
| ③ 逃窜期 | 33s 之后 | 出现 DART 疾冲，换向窗缩短到 0.22s |

- 难度倍率沿用 5.3：悠闲 ×0.75、激烈 ×1.3（只作用于速度，不动判定盒）
- **快抓反馈**（对齐萤光敏锐度）：本只存活 ≤2.5s → 下次 FLEE 速度 ×1.08、FLEE 占比提高；>6s → 放宽。上限封死
- 自适应辅助生效时：FLEE 速度 ×0.85、换向窗 0.35s
- 双爪天然兼容：两只爪子同时扑两只蝌蚪，双爪乱拍判定照常

## 8. 验收标准

1. 逃窜方向与最近拍击点相反（夹角 >90°）占比 ≥90%
2. 换向静止窗每 4–7s 出现一次、时长 0.25s±10%，位移 <4px、身体可见 C 形弯
3. 头/尾命中都是 +1；一次扑击只计一次命中
4. 重生全部从屏幕边缘游入，无屏内凭空出现；入场首段无停顿
5. 数量动态：连续打得好 2 个周期内上涨到 ≥3；连续打不动 2 个周期内降到 1；范围永不越界 [1,7]
6. 背景切换与捕鱼一致：滑动切换、跨局记忆、脏数据回落
7. 60 秒局总命中 12–20 次（假设区间，验证评级不畸高畸低）
8. 双爪、自适应辅助、悠闲/激烈倍率正常叠加且不互相抵消

## 10. 风险与反向指标

| 风险 | 表现 | 应对 |
|---|---|---|
| 尾巴太好拍 | 分数虚高 | 部位无敌 0.6s + 数量动态调节会自动平衡（打得好→目标多→单个更难顾） |
| 逃窜太快追不上 | 连续扑空弃玩 | 快抓上限封顶 + 自适应限速 + 数量自动回落 |
| 方向因果不可读 | 「等它转弯」不成立 | 换向 C 形弯 + 固定从拍击反方向逃 |
| 动态数量抖动 | 目标忽多忽少像 bug | 加减档都要连续确认 + 单次只 ±1 |
| 新背景包体 | 两套配色 + 装饰 | 全矢量复用现有技术，预计 +30–60KB |

反向指标：换向截击占比、逃窜期间拍空率、数量档位分布（长期停在 1–2 档说明加档条件太苛刻）。
