# 「小河戏鱼」改造说明

> 把原来的「泳池追鱼」模式（`pool`）整体换成参考图里的浅溪场景与河鱼造型。
> 玩法骨架（鱼不出屏 / 自由巡游 / 击中消失 / 全部消失后从边缘游入）保持不变，
> 只重做布景、鱼造型、以及鱼"入场"与"身周环境"的表现。

## 2. 新增 / 替换的资源

**没有任何新增二进制资源**：布景与鱼全部是 Canvas 2D 矢量重绘，不增加包体。
（包里 `assets/` 与 `generated-images/` 未改动，无需重新打包图片。）

| 资源 | 类型 | 说明 |
|------|------|------|
| `creekBedCache`（`js/scenery.js`） | 运行时离屏 canvas | 新增 1 张全屏缓存（`W×H×min(dpr,1.75)`，844×390@2x ≈ 4MB），存卵石/苔藓/水草/河石/岸边草 |
| `poolCausticsCache` | 原有离屏 canvas | 复用，只换传入参数（格子更大、线更淡），无新增显存 |
| 鱼造型 `D.poolGold` | 替换 | 侧视金鱼 → 俯视河鱼 `D.creekFish`（旧函数已删除） |

## 3. 性能设计（要求：多鱼同屏流畅）

- **静态层离屏缓存**：河床/石头/草全部只在「尺寸或布景种子变化」时画一次，每帧只 1 次 `drawImage`。
  缓存按 `dpr = min(devicePixelRatio, 1.75)` 渲染，2x 屏上省约 23% 显存。
- **跳帧重绘**：焦散光网沿用 `poolCausticsCache`，每 ~1/24s 才重算一帧（2–3 帧复用同一张）。
- **动态元素极轻**：涟漪 3 组 × 2 圈描边、浮叶 6 片、碎金 15 个、光斑 5 团径向渐变；
  鱼身环境层只有 1 次径向渐变 + 1 次椭圆描边。
- **实测**：本机 Chrome 无头跑 844×390@2x，**9 条鱼同屏稳定 60fps**（`test/probe_creek_visual.js`）。

## 4. 玩法保留点（对照需求 3）

| 原行为 | 改造后 |
|--------|--------|
| 鱼在屏内任意方向直线巡游、撞边反射 | 不变（`updatePoolSwim` / `pickPoolHeading` 未动） |
| 击中 → 缩小淡出消失（`vanishT` 0.3s） | 不变 |
| 消失后重生 | 改为**从河岸边缘游入**：贴边落位、航向朝内、0.5s 淡入，并带一圈入场涟漪（更符合"浅水里从岸边游进来"的直觉） |
| 同屏 1 / 3 条，按阶段与「小鱼数量」设置 | 不变 |
| 鱼全程不出屏 | 不变 |
