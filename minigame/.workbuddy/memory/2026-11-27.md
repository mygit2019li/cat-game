## 抖音小游戏上架调研（微信小游戏 → 抖音小游戏）

产出：`docs/抖音小游戏上架流程与适配清单.md`（完整流程 + 资料清单 + 本项目适配清单 + 官方文档索引）

### 核实过的官方口径（developer.open-douyin.com）
- 主体认证：个人=身份证+手机号/银行实名（~1工作日，可建50个小游戏，仅广告变现）；企业=营业执照+对公验证（~3工作日，100个，可开内购）。**主体类型审核后不可改**
- 软著：所有游戏必填；平台支持电子软著准入但**不支持用于小游戏备案**（备案须国家版权局登记证书）；著作权人须与主体完全一致；同一软著只能对应一款在线游戏；游戏名须与软著名一致
- 自审自查报告：自 7/11 起改为后台勾选确认，不用上传
- 版号：仅开通内购 / 已有版号时需要
- **备案顺序不可颠倒**：小游戏备案（无版号，平台代申报，需先过基础信息+版本提审）→ ICP 备案（所有类型）→ 发布
- ICP 备案：平台审核 1–3 工作日 + 管局 1–3 周 + 工信部短信核验；**提交后不可撤回**
- 提审：上传时预检，**未接 `tt.navigateToScene`（侧边栏复访，必接）直接上传失败**；2026-04-20 起提审自动上线至所有已接入宿主，QA 默认多端回归
- 包体：不分包 20MB；分包后整体 20MB、单主包 ≤4MB、单子包 ≤20MB；开放数据域 ≤4MB
- 迁移工具：IDE 内置「搬家」+ npm 包 `wx-to-tt`（`wx2tt -i <src> -o <dst>`），日志在输出目录 `__wxToTT/report/index.html`

### 本项目（逗猫猎场）适配要点
- 现状：主包 ~1MB、assets 子包 2.81MB → **包体完全达标，不需瘦身**
- wx API 用量：61 个不同 API，分布 12 个文件（game.js / js/{ad,audio,config,draw,feeder,platform,scenery,sharecard,ui}.js / assets/game.js / openDataContext/index.js）
- 🔴 **`wx.createCustomAd` 抖音不存在**（仅 banner/激励视频/插屏/GridGamePanel）→ `js/ad.js` 整套浮卡自定位逻辑需整体重写，不建议缝补
- 🔴 **需新增 `tt.getGameRecorderManager` 录屏分享**（当前只有录音），抖音靠短视频分发，缺此等于放弃主分发通道
- 🔴 **必须接侧边栏复访**（`tt.navigateToScene` + `tt.onShow` 判断 `launch_from==='homepage' && location==='sidebar_card'`），否则版本上传被拦
- 🟠 `wx.getMenuButtonBoundingClientRect` → `tt.getMenuButtonLayout`，**单位 px → dp**；抖音胶囊旁还有「游戏中心」按钮，官方无接口
- 🟠 `wx.chooseMessageFile` 抖音无对应 → 用户素材选择需降级
- 🟡 `wx.reportEvent` → `tt.reportAnalytics`/`tt.reportScene`；`wx.createWebAudioContext` → `tt.getAudioContext`；`wx.env.USER_DATA_PATH` 路径体系待实测；`scope.WxFriendInteraction` 无对应
- 广告频控：插屏启动后 30s 内不可展示，两次间隔 60s；激励视频横屏会切竖屏

### 结论
代码适配约 3–5 天（广告重写 2 天 + 录屏 1 天 + 其余 1–2 天）。软著是关键路径（免费 30–60 工作日 / 加急 10–15 天），应最先启动。
