## 修复：动物情绪(sound)横屏广告真机不出
- 用户反馈真机横屏 sound 广告没出来。诊断脚本（`/tmp/ad-shot/diag_sound.js`）模拟原生广告 `onResize` 回传实测高度：h=60/80 正常，h≥100 时 `soundAdRect` 返回 null → `ad.realign()` 立即 `leave()` 销毁已 show 的实例，alive=0。浏览器垫片不回传高度（用估算 80）所以测试全绿测不出来。
- 根因：`soundAdRect` 用实测高度做"淘汰判定"（`if (h>bandH) continue`），而右上窄带可用高仅 ≈81，真机素材常 100+，所有候选被跳过。
- 修法（`js/ui.js` soundAdRect）：实测高度只用来定 top（让下缘贴网格上沿），高度一律 `Math.min(rawH, bandH)` 截断，不再淘汰候选——浮卡本就允许遮挡，宁可略溢出也保证出得来（与 result 横屏一致）。
- 探针加回归：回传 h=100/120 后断言 `ad.state().page==="sound" && shown===true`、rect 有效。
- 另修：`homeAdRect` 竖屏分支的 `bottomH/bottomY` 被外部误改成 `30 / -104`（与 drawHome 的 `60 / -14` 不同步，注释要求同式），导致竖屏首页广告放不下、探针 3 项失败。改回与 drawHome 一致后全绿。
- 结果：`test/probe_ad_placements.js` 全绿、0 运行时错误。
- 教训：原生广告"测试真机不一致"优先查 `onResize` 实测尺寸回传后的 realign/leave 链路，垫片不回传尺寸会掩盖这类问题；凡"实测高度放不下就不出"的页面都要确认窄带场景不会被真机素材高度淘汰。

## 修复：大屏横屏广告不展示（1366×1024 那档）
- 用户反馈大屏横屏广告没正常展示。诊断脚本 `/tmp/ad-shot/diag_big.js` 测 1080×608 / 1366×1024 / 1920×1080 三档：只有 **1366×1024（S=2，虚拟 683×512）** 出问题——首页 `homeAdRect=null`、动物情绪 `soundAdRect=null`，其余页面正常。
- 根因：两页可用宽度都刚好 **118px**，比 `MIN_WIDTH=120` 差 2px 被判"太窄不出"。首页 `width=W*.173=118`；情绪 `bandW=rightLimit(626)-leftLimit(508)=118`（leftLimit=tab右缘+64）。
- 修法（`js/ui.js`）：① 首页宽度加保底 `Math.max(120, round(W*.173))`（右缘不动、左缘左移 2px）；② 情绪页停止键预留 64→58（bandW 变 124）。改后该档 home `{532,24,120}`、sound `{502,17,124}`，5 个页面全 show。
- 探针加"大屏横屏 1366×1024"段 3 条断言守 MIN_WIDTH 边界，全绿。
- 教训：按屏宽比例算广告宽度时，虚拟宽较窄档（如 S=2 的 683）容易刚好卡在 MIN_WIDTH 下方几 px → 整页不出；比例公式一律配 `Math.max(MIN_WIDTH, ...)` 保底，避免"大屏反而不出"的反直觉 bug。

- 建体检矩阵 `/tmp/ad-shot/audit_all.js`：9 档大屏（1024×768~2560×1440）× 6 个广告页（home/sound/bgpick/result/summon/feeder），查 rect 非空 / 宽>=120 / 不越界 / 实例 show。另 `audit_height.js`：4 档×4 页×4 种回传高度(60/96/120/160)，查隐藏/top越界/未展示。

## 首页横屏广告改「紧贴顶部」（不再往下移）
- 诉求：广告不要往下移，紧贴顶部。
- 根因：上一版右缘贴屏幕最右(W-safe.right-8≈789)超过了胶囊左缘(750)，ad.fit 检测到与胶囊相交，自动把卡挪到胶囊下方 → 表现"往下移"。
- 修法（`js/ui.js` homeAdRect land）：`top=safe.top+8`（贴顶）、`rightLimit=menu.left-8`（右缘止于胶囊左侧，水平不相交→不触发 fit 下移）、宽仍 W*.173 保底120、left=rightLimit-width。新落点 `{596,8,146}`。
- 关键认知：ad.fit 的胶囊避让会把"贴顶但右缘过胶囊左缘"的卡下移；要贴顶就必须让广告右缘 ≤ menu.left。
- 探针断言改为 top 4~16 / 右缘 720~750（胶囊左侧），全绿；图 `screenshots/首页横屏_广告贴顶.png`。
