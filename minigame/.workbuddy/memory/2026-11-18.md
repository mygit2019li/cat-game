
## 二级页面返回键：圆形 → 胶囊「‹ 返回」（用户「不要做成圆的，换一种风格」）
- 范围：4 个从首页进入的二级页面顶部返回键——场景选择(bgpick)/动物情绪(sound)/召唤猫咪(summon)/电子猫粮机(feeder)。
  之前全是 chipBtn/feeder roundBtn 画的「白圆 + 青绿细描边 + 左箭头」。
- 方案：ui.js 新增共用基元 `backPill(x,y,h,o)`（放在 chipBtn 后，暴露 `ui.backPill` 给 feeder.js）：
  横向圆角胶囊(h/2) + ‹ 箭头 + 「返回」文字，白底 + rgba(21,154,140,.32) 1.4px 细描边，无阴影；
  宽度按字号自适应(o.fs/pad/gap/w/r 可调)，返回实际 w 供调用方把后续元素顺移。命中区随之变横向(w×h)。
- 改动点：bgpick 标题起点 `edgeL+backW+F(16)`；sound 分享键 `bX+backW+8`；summon 自定义键 `bX+backW+10`；
  feeder 用 `G.ui.backPill` 且因顶部紧传 `{fs:13,pad:8,gap:5}`，`backExtra=bw-s` 存在模块变量，
  headPos() 对 i>0 键加该偏移让设置/分享顺移，标题间距 14→9 避免贴储粮罐。
- 验证：语法 check OK；shot_sec.js 四页两视口零报错；verify_backpill.js 16 项 ALL PASS
  （4 页返回键均横向胶囊 w>h、点击回首页、零报错）；verify_final.js 五视口几何 ALL PASS。
  备份 /tmp/cat-green/bak/{ui,feeder}-before-backpill.js；对照图 screenshots/二级页面返回键_改版对照.png + 四张单页。
- 经验：换按钮形状时，紧随其后的兄弟元素(标题/图标键)必须按新宽度顺移，否则重叠；feeder 顶部三键等距靠 headPos 统一偏移最省事。
