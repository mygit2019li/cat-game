## 参考视频分析：猫咪平板逗猫游戏的「猎物与动作」
- 素材：用户发来的 23.9s 手机实拍（720×952 / 30fps），猫（布偶/重点色，穿蓝色胸背带）趴着玩平放的 iPad。
- 场景：前 15.3s 是**俯拍枯草地**（写实干草+碎石，暖褐调，压暗）；15.3s 后整屏切到**龟裂焦土**（暗红底 + 灰白裂纹多边形），是**整体切换/换关**，不是局部烧痕。
- 猎物：一团**暖色发光体**（黄/红/橙三种色调），中心极亮 + 橙色柔光晕 + 尾随细小火星；等效直径约占屏宽 **7.4%**；亮度/面积**约 1.9 次/秒脉动**。
- 动作：缓慢漂移，均速约 **15–44% 屏宽/秒**（多数 35–45%）；24 秒内 9 段出现，段长 0.5–5.1s，段间隔 0.1–1.7s（消失→别处重新出现）；**两次硬瞬移**（t=1.80s 位移 86px≈36% 屏宽、t=4.53s 93px≈39%）。
- 命中反馈：炸成 10–20 个青白/橙色小光点四散，猎物本体立刻消失，约 0.1–1s 后在别处重生。
- 猫的动作：几乎全程趴卧、鼻尖距屏幕 10–15cm；抬前爪拍击为主（可见 5+ 次），偶有低头用鼻/嘴去拱；注意力高度集中，命中率很高。
- 对我们 6 种玩法的启示（未实施）：发光+脉动是最强的注意力钩子；慢速大目标 + 高命中率更适合真猫；
  瞬移要"淡出→淡入"而不是硬跳；命中爆炸用对比色（青/白）点在暖色里最跳。
- 产物：`screenshots/ref-video/`（gallery_prey 四种猎物形态特写 / timeline 出现区间与脉冲 / scene_compare 两套背景 / sheet_01 逐秒总览 / strip_9_12 移动轨迹）。
- 方法：ffmpeg 抽帧(15fps, 360 宽) → HSV+局部亮度对比定位光斑 → 逐帧质心/面积/跳变统计 → matplotlib 画时间轴。

## 按参考视频改造「暗夜萤光」（pool）——已实现
- 背景：`scenery.js` 把石板墙换成**俯拍枯草地**（暖褐底 + 约 2700 根干草秆 + 草屑 + 碎石 + 暗角 0.46）；
  草/石只画一次进离屏 canvas（`grassCache`，key=W×H+seed），重建 ~4ms，命中缓存 0.02ms/帧。
- 猎物：`draw.js` `D.poolLight` 重写为**会呼吸的光球**（近白内核 + 暖光晕 + 3 颗青白小火星 + 贴地光斑），
  尺寸/亮度用逻辑层给的 `pulseK`（1.9–2.3Hz）。
- 运动：`prey.js` 用 `updateDrift` 取代 `updateCrawl`（爬行虫子逻辑整段删除）——
  缓慢随机转向 + 软回弹/镜像反弹；速度 150/172/196 px/s（实测 152 px/s ≈ 屏宽 43%/s，对齐视频 35–45%）；
  每 7–10/5–8/4–6 秒"熄灭(0.22s)→换点(≥42% 短边)→亮起(0.3s)"；被拍 0.08s 收光；未命中阈值放宽到 fade≥0.08。
- 命中：新增 `G.lightPop`（15–22 暖橙碎光 + 6–10 青白冷光 + 8–12 条放射亮线 + 双圈 + 闪白 0.10/0.16），
  并把 pool 的水面涟漪换成"不画"（干地上出现水圈很违和）；飘字抬高到 y-56。
- 参数：`G.POOL_DRIFT = {1:{speed:150,pulse:1.9,tele:[7,10]}, 2:{172,2.1,[5,8]}, 3:{196,2.3,[4,6]}}`。
- 文案：首页卡片描述改为"萤火在枯草地上慢慢飘"；`docs/游戏规则.md` 第 5 节整段重写。
- 测试：新增 `test/shot_pool_look.js`（背景取样/漂移速度中位数/脉动幅度/瞬移距离/命中粒子双色/阶段③5只/横竖屏）。
- 顺手修：`draw.js` 蝴蝶 HD 贴图在浏览器垫片里没拼 `../`，导致 shot.js 的 butterfly/mouse/laser 报 ERR_FILE_NOT_FOUND
  （真机不受影响）；改为按 `location.pathname` 判断是否在 test/ 下再拼前缀，现在全模式 errors: none。
- 踩坑：①"净位移"测速度会被随机转向吃掉，要量**路径长度**并取多只中位数；
  ②软回弹不足以防"贴墙蹭"，必须加镜像反弹；③`glow:true` 的实心冲击环在白光下会变成米色斑，改用全屏闪白更干净。

## 暗夜萤光：按参考视频 1:1 重做（动物 / 动作 / 特效 / 音效）
- **先认清动物**：把视频帧裁到 26px 再 10x 放大 + UnsharpMask，才看清是**萤火虫**——
  两片圆钝猩红鞘翅（#F7263F）+ 中间金黄发光腹部（#F4C013）+ 腹部两侧青白光点 + 金色双卷须 + 六足。
  （之前那版只做了"发光球"，形状完全不对。）
- **动作靠量化**：15fps 逐帧质心 → 帧速度中位 18% 屏宽/s、90 分位 53%/s、段落内 CV 2.1 → 结论是
  **两档步态"慢爬/急爬"交替**，不是匀速漂移；且**身体朝向固定朝上不旋转**（视频里轮廓始终是正的）；
  红色面积会周期性翻三倍 = **鞘翅开合**，2–4s 张一次；自发换位 24s 只有 2 次。
- 实现：`js/draw.js D.poolLight` 整段重写为真虫子（底光/六足/腹部/发光点/鞘翅/胸节/头/触须/lighter 溢光）；
  `js/prey.js updateDrift → updateFirefly`（两档步态、步态相位跟速度走、鞘翅开合时间线）；
  `js/config.js G.FIREFLY`（slow/fast/gait/fastP/pulse/flare/tele，三阶段）。
- **音效按音轨实测**：视频音轨里拍中那一下重心 0.99kHz、衰减 28ms → `tools/gen_firefly_sfx.py` 合成
  `firefly-hit.wav`（重心 1.07kHz，0.19s）+ `firefly-flare.wav`（1.6–3.6kHz 极轻摩擦）。
  限流：拍中 70ms、张翅 900ms。
- 命中特效从"大水花+双环"改成**一小把白/金碎光 + 青白点 + 一圈很细的暖环**（视频里就是散成几颗小圆点）。
- 背景：草秆更亮更长、往中间堆（视频里是一堆稻草），底色改暗紫褐，草秆双描做出柔边。
- 测试：`test/shot_firefly.js`（造型特写/张翅/命中/步态两档/鞘翅开合区间/音效触发/预取/阶段③5只/横屏）。
- 踩坑：①鞘翅张开如果用"大幅旋转"，两片会叠成心形 → 改为"分开 + 放大 10% + 轻微旋转"；
  ②金色必须画在鞘翅**之上**（lighter 叠一层）才像"光透出来"，画在下面会被红瓣压住。

## 用户指出视频里有多种猎物 → 补齐三物种
- 逐段重看 9 个出现段 + 9 个时刻 10x 放大，确认至少 3 种：
  ① 金甲虫（1.9–4.8s，盾形金黄 + 中央橙斑 + 中缝，**横躺**、体型最大）
  ② 红萤火虫（13–14.5s，已实现的那只）
  ③ 橙光虫（0.3/7.7/20.3–21.3s，橙色光 dome + 4 颗大青色光球 + 白火花，光雾最大）
- 实现：`js/draw.js` 把原红萤火虫改 `_ffRed`，新增 `_ffYellow`（贝塞尔盾形 + rotate(π/2) 横躺）与 `_ffOrange`（dome + 大青球 + 白火花），`D.poolLight` 按 `p.species` 分发；
  `js/prey.js` 顶部加 `pickFfSpecies()`（红 32%/黄 34%/橙 34%），出生抽取、被拍重生（relocate(fresh)）时换种；
  `js/scenery.js G.lightPop` 加 species 参数（FF_POP_COLORS 三套配色）；game.js 传入 prey.species。
