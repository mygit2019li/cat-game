## 追加修正：动作改成「一点点往前小跳」，不是随意乱飘
- 用户指出上一版「持续自转 + 随机转向 + 匀速滑行」不对。重新用 **30fps**（之前只有 15fps）逐帧量化，
  结论完全推翻旧判断：
  - 相邻帧位移：0–1px 占 **41%**、4–8px 占 **46%**、无 ≥16px → 长时间停顿 + 连续小碎步。
  - 走/停分段（5–12s）：走 0.87s → 停 1.97s → 走 3.13s → 停 0.9s，**停时位移严格为 0**。
  - 相邻移动**方向夹角中位 2.7°、90 分位 10.2°** → 一直朝前，不随机转向。
  - 主轴角变化中位仅 **1.9°/帧**（90 分位 79° 是 PCA 在近圆形状上的伪影）→ **不持续自转**。
- **教训**：15fps + PCA 主轴角会把「形状近圆时的角度跳变」误读成持续自转；
  判断动作必须看 30fps 的**位移分布直方图 + 走停分段 + 方向夹角**，不能只看平均速度/角度方差。
- 实现：
  - `config.js G.RABBIT` 参数换成 `step`（屏宽%/步）/ `hopDur` / `hopGap` / `walk` / `rest` / `turn`，
    三阶段 8/9.5/11% 屏宽每步；速度 ≈ step/(hopDur+hopGap)。
  - `prey.js updateRabbit` 重写：**走 1.2–3.4s / 停 0.6–1.5s 交替**；走段内 `hopPhase` 循环，
    前半段用 `v = step/hopDur*(1-0.55k)*norm`（积分恰好等于 step，前快后慢），后半段 `hopGap` 落地静止；
    方向段内固定（换走段最多 ±6–8°、只在边界镜像反弹）；`baseSpin` 每段固定（竖直/横躺），
    每跳只轻摆 ±5°；`hopLift` 给绘制用。
  - `draw.js` 加 `hopLift`：跳起时身体略抬 `0.10R` + 放大 4.5%，**贴地影仍留在地面**（ffBase 在变换之前调用）。
  - `test/shot_rabbit_mode.js` 实测项改成 `stillPct / turnMedDeg / walkSwitches / spinChangeDeg`，
    并新增 `screenshots/rabbit-motion.png`（6 秒轨迹：黄=小步前跳、蓝=停顿、亮点=腾空）。
- 实测：`stillPct 52%`（视频 41%，已收短 rest 靠近）、`turnMedDeg 0`、`spinChangeDeg 0`、
