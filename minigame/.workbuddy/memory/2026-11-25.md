## 老鼠腿部步频 × 移动速度匹配（俯视 run 循环频闪 bug 修复）

用户要求「老鼠的腿部动作和移动速度要进行匹配」。

### 根因（单位错误）
- `p.def.speed`（= `G.PREY_DEF.mouse.speed`）是**绝对 125 px/s**，但 draw.js 俯视图四条渲染路径的步频公式全把它当 **≈1 的倍率**用：
  - `_mouseVideoTop`（主路径，16 帧 run 循环）：`fps = 4.5 + spd` ≈ **129fps** → 16 帧循环 ≈8 圈/秒频闪；
  - `_mouseReal` / `_mouseTopRig`：`freq = 3.x + spd*0.5` ≈ **66Hz** 程序化起伏/四腿摆动；
  - `_mouseTopHD`：`speedK = clamp(0.6, 1.45, def.speed*mSpeed)` 恒顶格 1.45，不随速变。
- prey.js 其实早已暴露真实位移速度 `this._moveSp`（px/s，scurry L1062 / dart L1150），侧视 dart 的 fast vseq 已在用它（`clamp(10,60,_moveSp*0.16)`）——只有俯视侧漏接。

### 修复（js/draw.js，4 处，均为 realSp 驱动）
`const realSp = p._moveSp || ((p.def && p.def.speed || 125) * (p.mSpeed || 1));`
- `_mouseVideoTop` scurry：`fps = min(16, max(5, 3 + realSp*0.03))`（100→6 / 250→10.5 / 433+→16 封顶）；**相位改 dt 积分**（`p._mvPhTop += dt*fps`，`p._mvLastTTop` 记录，dt 夹 0.1s），速度/停驻切换步频平滑不跳帧；首次用 `phase*0.5` 播种错开群鼠；bob 改用 `|sin(ph*0.4)|`（周期≈15.7帧≈一个循环，与腿同相）。
- `_mouseReal` / `_mouseTopRig`：`freq = min(7.5, max(2.5, 1.5 + realSp*0.0135))`（125→3.2Hz / 250→4.9 / 400+→6.9）；`amp = min(1.2, 0.55 + realSp*0.003)`。
- `_mouseTopHD`：`speedK = clamp(0.6, 1.45, realSp/150)`（100→0.6 … 242+→1.45）。
- 侧视 dart fast vseq 本就速度驱动，未动；peek look（8fps 张望）与 sit（停驻）非步态，未动。

### 验证（test/shot_legspeed_check.js，Chrome headless）

## 老鼠身上"斑块闪动"诊断：源自视频帧素材（待用户确认后替换 sheet）

用户问：老鼠身上的斑块+闪动是不是截取视频帧导致的？→ **是，证据链完整**。

### 三层证据（Python 分析，locateanything env）
1. **灰鼠 base sheet 本身就有斑块**：look_sheet f3 鼠身内部 10002px 中 630px 低频亮斑(>+10级)/267px 暗斑(<-10级)≈9%；3× 放大可见整个身体布满 4-8px 马赛克方块（H.264 压缩块）。
2. **原始彩色视频帧也有**：run-house_03 鼠身 25590px 中亮斑 1797px + 暗斑 1978px≈14.8%，腹部有大块柔和亮斑（视频自带光照）。
3. **LUT 是"放大器"不是"制造者"**：解码 draw.js 内嵌 LUT（6花色×3通道×256，4608B）——斜率 1.0~1.27 RGB/亮度级，把 ±15 级亮度差转成 ±20 级色差；且每花色 68~106 个 1-2 级非单调点（轻微 banding 加重）。
4. **闪动机制**：look sheet 14 帧 = 8 唯一帧乒乓；帧组间亮度 124.4 vs 122.2（跳 2.2 级），姿态变化使光斑/噪点逐帧移位变形 → 斑块"出现+闪动"。

### 修复方案（离线处理 3 张 base sheet，零代码改动，A/B 已验证）
- 每帧格：erode(alpha) 取鼠身 → 31px 高斯残差×0.85 压掉低频光斑 → 低梯度区(lap<5,羽化) 9px 模糊清马赛克 → |L−Lmed|≥50 的高对比细节（眼/胡须/内耳线）还原保护 → np.where(body) 只改身内。
