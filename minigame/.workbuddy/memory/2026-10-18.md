## iPad/大屏适配（全局缩放因子 S）
- 新增 `G.platform.S = clamp(sqrt(W*H / (390*844)), 1, 2.0)`，由 platform.js 在 init 与 onWindowResize 时计算。
- UI 适配做法：所有 UI 屏幕在「虚拟手机尺寸」里布局（`layout()` 返回 `W/=S, H/=S, safe/=S`），由 `game.js` 的 `uiScaleCtx()` 用 `ctx.scale(S,S)` 整体放大——字号/尺寸/按钮自动等比放大且居中不溢出。
- 触摸命中：UI 按钮与 pauseRect 都存虚拟坐标，onTouchStart 把 touch 除以 S 后再做 UI 命中；猎物命中仍用真实坐标。
- 猎物：在 `prey.js applySize` 的 `this.sc` 乘以 S（视觉与命中框同步放大）；移动速度按 `sqrt(S)` 轻微提速，避免大屏显得迟缓。
- 修复：大屏下暂停按钮顶出屏幕——虚拟 36×36 按钮放大后比胶囊高，与胶囊垂直居中的补偿量为负；在 ui.js 横屏分支加 `py = max(py, safe.top + 6)` 钳制。
- 首页合规小字改版：横屏时四条提示（适龄/健康忠告/安全/免责）不再堆在左栏折 8 行，改为通栏放屏幕最底部、`fitTips2()` 平衡折成两行（字号 10→7 自适应、句读处断行、放不下退多行）；右侧卡片垂直区域用 `cardAvailH = availH - tipsH` 避开提示条。竖屏仍走原 drawTips 全宽折行。

- 改了：platform.js / ui.js(layout+drawHud+drawCountdown+drawPause+showLB) / game.js(uiScaleCtx+触摸换算) / prey.js(尺寸+速度)。手机 S≈1 行为不变。

## 好友排行功能检查（只读审查）
